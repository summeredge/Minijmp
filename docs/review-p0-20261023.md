## 统计定义

- ANOVA：H0 为相应模型项系数为零，条件于模型中其他项；沿用 III 型 SS、和对比编码及误差独立同方差假设。F 的分母为当前模型的实际残差均方，p 为 F 分布上尾。独立参考用 NumPy 最小二乘与删去相应列后的受限拟合构造 SS，不调用生产模型实现。
- Fisher：条件于固定边际，H0 为两组成功概率相同；双侧累计所有概率不大于观测表的支持点，包含数学并列；单侧沿用超几何 CDF/SF。独立组合数使用整数比较，无浮点容差。非并列反例 `(n1,n2,e1,e2)=(1000001,1000000,0,1)` 拒绝把过宽容差当作并列；生产实现复用 SciPy 的并列处理，无新增容差。
- Clopper-Pearson：反演二项分布尾概率，双侧每尾 α/2，单侧每尾 α；0 成功的下限为 0，全部成功的上限为 1。独立参考为 SciPy `binomtest(...).proportion_ci(method='exact')`，另以端点闭式 `1-(α/2)^(1/N)`、`(α/2)^(1/N)` 验证。
- 未定义近似：零标准误时不伪造 Z 或 p，保留精确检验；区间也标记 NA。Fisher 独立参考不依赖正态近似。
