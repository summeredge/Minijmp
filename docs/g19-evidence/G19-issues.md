## A 类：已实施局部修复

### A-01：两比例 Fisher 搜索在 PMF 下溢后不终止

- 入口：`Prop2SDialog.apply → proportion_test.prop_2sample`，同步进入当前 GUI；独立函数也受影响。
- 输入：`n1=n2=10000，e1=1，e2=9999`，以及交换两组事件数。
- 修改前证据：`defect-reproduction.json` 记录观测 PMF=0、真实子进程 10 秒超时并终止。新回归用真实超几何分布，但在第一次越界 PMF 请求时立即失败，避免测试自身挂死；`fisher-before-tests.txt` 两个参数均失败。
- 根因：两个 while 只比较 PMF。超出有限支持集后 PMF 仍为 0，`0 >= 0` 永远为真。
- 修复：读取真实支持集，分别将向右和向左搜索限制在上下界内。保留原 `>=` 极端性比较、CDF 组合、字段、报告和正常输入语义；未替换 Fisher 方法。
- 验证：修改后相关回归 308 passed，最终完整回归 2098 passed；独立 Patch Review 未发现局部修复阻断项。新增测试核对返回 p 值、有限调用次数、报告原值与 SciPy 在该下溢输入上的结果。
- 残留界限：此修复保证有限支持集内终止，不宣称解决所有极小概率精度、CDF 相减消差或旧方法并列概率定义问题。

## B 类：记录后待确认，不修改统计定义或架构

### B-01：独立 `p_likelihood_ratio` 入口的 LR 极端性排序与通常定义不符

> G20 更新（2026-10-21）：此项已修复并解除。逐支持点 MLE 的独立参考验证、旧错误拒绝试验及完整回归 2185 passed 均通过，详见 [G20 审查报告](../g20-evidence/G20-review.md)。下列内容保留为 G19 当时的缺陷证据。

- 位置：`code/proportion_test.py::p_likelihood_ratio`。当前主程序没有生产调用者；专项测试、性能脚本和外部直接调用可进入。正式单比例报告没有调用它。
- 当前输出：`p_likelihood_ratio(10, .5, 8) = 0.9785156249999998`，见 `defect-reproduction.json`。
- 参考：按每个支持点自己的极大似然计算二项 LR，`p0=.5` 时极端支持点为 `{0,1,2,8,9,10}`，其精确概率为 `2*(1+10+45)/1024 = 0.109375`。当前实现固定 `p=x/n`，再用 `min(i,n-i)` 与 `LR(y)>=LR(x)`，选入的是 `2..8`，概率 `0.978515625`。
- 归因：固定旧实现已经如此；G16 差分测试保留了旧公式。测试通过只能证明兼容，不能证明方法正确。
- 处理：不刷新基线、不改公式、不新增一个断言错误值正确的测试。需要先确认此公开辅助入口应承诺的统计定义、边界输入和兼容影响，再用独立参考修复。
- 影响：当前 GUI 正式报告未受该入口影响；直接使用该函数可能取得不符合通常 LR 定义的 p 值。这是未解决的统计结果问题，不能据全套 pytest 通过给出 PASS。

### B-02：同步 Excel、完整 ASCII 与原始点绘制的既有等待成本

普通 Workbook 和全部表格字符串仍随数据量增长，Excel 导出同步；时序保留全部原始点。新增线程、任务队列、流式失败清理或缓存状态机会扩大本任务范围。以本轮分阶段性能记录说明实际成本，未有确定收益和兼容性方案前不更改架构。

### B-03：人工交互及外部环境验收

真实系统剪贴板往返、实际 Excel/LibreOffice 打开、真实 PI SDK/服务器、全部 DPI/主题、物理鼠标手感和长期资源趋势待人工验收。真实 Tk 自动脚本、拦截剪贴板写入和离线 PI 协议测试不能替代这些项目。详见功能报告。

## C 类：核对后保留

- 两版相关矩阵均保留：当前 GUI 使用 `multi_fit`，`multi_fit_orig` 为公开保留入口；两版分别验收，不为统一布局重写接口。
- 主表与 vendor 查找有整格/正则、坐标顺序等差异；两个真实实现均核对，不强行合并。
- `df_combine` 覆盖粘贴、带表头粘贴和堆叠；关系型 Combine 使用 pandas merge/concat，是不同语义。
- CSV 预览、用户确认与正式读入之间文件及选项可变化；保留每次读入校验，不做跨调用缓存。
- G14 分页、累计控件预算、idle 滚动取消、完整 TXT/复制与 PNG 分配前限制均有实际消费者和保护测试，不移除。
- G17 嵌套对象疑点未复现：本轮对同形 list/ndarray object 列与覆盖合并的探针均完成，未发现广播异常；不把证据缺口写成缺陷，也不增加转换框架。
- 历史文件和 `*_orig.py` 分类保留；不凭文件名判定无消费者，也不执行清理。
- `iloc` 出现本身不构成热点：按列取值、边界检查和非热点小循环可保留，性能结论以实际规模与计时阶段为依据。
