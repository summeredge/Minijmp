# DOE 工作包 H 方法合同（H0）

日期：2026-10-29。此合同先于 H 生产代码固定。Minitab 在线帮助用于确认产品工作流与方法边界；MiniJMP 的数值正确性由 `tests/fixtures/doe_h_reference/` 中的独立案例验证，不以数值相等替代数学验证。官方网页没有注明适用的 Minitab 版本。

## 二项响应：ACC-004、ACC-019、ACC-031

每个 DOE 运行输入整数 `events` 和 `trials`，必须满足 `trials > 0`、`0 <= events <= trials`。按分组二项似然使用 logit 链接：

`logit(p_i) = x_i β`，`events_i ~ Binomial(trials_i, p_i)`，`p_i = expit(x_i β)`。

设计矩阵取自已有 DOE 设计和模型项实现，不把事件率当作连续响应。系数检验报告 Wald z；模型/项比较使用嵌套模型似然比 χ²。仅将浮点容差内的微小负 LR 归零；若似然差显著为负，则该比较不可用并停止输出模型检验 p 值。`model_df = rank(X) - 1`，残差 deviance 的参考自由度为设计行数减模型秩（不是总试验次数减秩）。同时报告系数标准误、模型 LR、残差 deviance/Pearson 统计量及按 run_id 映射的拟合概率。二项模型不套用连续响应 ANOVA F、纯误差或失拟检验。

| 验收 | 合法模型矩阵 | 明确边界 |
|---|---|---|
| ACC-004 DSD | 复用已验证 DSD 编码；主效应、连续因子平方项、二因子交互按既有层级规则选项。 | 设计矩阵秩亏时拒绝拟合并指出非估计项；不支持全零/全事件、完全或数值上近完全分离的有限推断。 |
| ACC-019 Factorial | 两水平全因子使用 coded ±1；正规分数按完整别名组建模；General Full Factorial 将数值标签仍作为类别并用 contrasts；PB 首版只拟合主效应，交互混杂明确保留。 | 只在设计族已有正规矩阵上分析；不可估计项不报唯一系数/p 值；不实现自动选项或 Firth 修正。 |
| ACC-031 RSM | CCD、BBD 与 Schema v5 声明的 custom RSM 复用 `TermModel`；使用已有编码、模型项、层级和区组列。线性、交互、二次项由设计/模型定义决定。 | 秩亏、分离、全零/全事件或不收敛时不输出误导性 p 值/概率图；不对二项模型套连续响应失拟/置信区间。概率图只画合法模型域内的预测概率。 |

官方 RSM 二元响应总览还把拟合后的 Response Optimizer 列为下游工作流，通用响应优化器允许对 [0,1] 概率设最小、最大或目标。H4 的明确交付范围是模型、推断、概率预测和适用概率图；本包不增加二元 Response Optimizer 界面或 desirability 规则，也不改变既有连续响应 DOE-4 优化器。此边界在 feature matrix 中单独标明。

所有二项输出使用同一 grouped-binomial 核心，但不合并设计身份或设计矩阵：Factorial 子类型、DSD 实际矩阵和 RSM `TermModel` 分别校验。设计行顺序来自经过工作表指纹验证的 DOE run map，不按 DataFrame index 猜测。

## Factorial Variability：ACC-020

只接收至少两个因子的两水平 Factorial 设计。预处理支持两种不同实验单位：

1. **同次运行重复测量**：同一 DOE 运行的多个响应列；逐运行计算 Mean、样本 SD（分母 `n-1`）、有效测量数和缺失数。
2. **独立运行重复**：一个响应列中，相同因子设定且同一区组内的不同 run_id；按设定与区组分组计算 Mean、样本 SD、重复数和 run_id 列表。不得跨区组汇总。

SD 模型为 `ln(SD) = X γ`。首版使用等权最小二乘；只有每组测量数相等、无缺失且 SD 均为正时才拟合并提供 F/p。报告的模型项为两水平因子主效应，区组作为固定区组项；系数效应为 `2γ`，回归误差自由度为有效 SD 行数减设计矩阵秩。饱和模型、零残差方差、秩亏或非正误差自由度时只给可识别的摘要/估计，不报告 F/p。

零 SD 是合法的预处理结果，但 `ln(0)` 不存在，因此保留为 0 并标记模型不可用；0/1 个有效测量时 SD 缺失，不用 epsilon、填充值或静默删行。输入含缺失或各组样本数不等时仍显示 Mean/SD/N 摘要，但不声称等权推断。Split-Plot 整区/子区有不同误差单位，首版拒绝该设计；不实现官方另述的正态 MLE 或未核实的不等权公式。原响应列不被覆盖。

## DOE 功效与样本量：ACC-059、ACC-060

功效对当前工作表已验证的 DOE 设计点集规划**完整、等次数重复**，无需已观测响应；用户输入 `alpha`、目标因子、有限且非零的带符号效应差 `δ = mean(high)-mean(low)`、外部误差标准差 `σ`，并选择固定重复数或目标功效。当前检验是非方向性的一自由度 F 检验，非中心参数使用 `δ²`；效应方向不改变功效或样本量，`δ=0` 仍拒绝。模型为截距、所有因子主效应及受支持的区组项；当前首版限定为无区组、无中心点的两水平设计，一次检验一个 1 df 主效应。正规分数报告别名组效应；PB 主效应须注明与未拟合交互的混杂假设。

ACC-059 支持现有两水平全因子和正规部分因子；ACC-060 支持现有 PB 和 General Full Factorial 的**所有因子均为两水平**子集。General Full Factorial 的数值水平按类别标签编码。多水平因子的多自由度效应需要完整对比向量，单一最大-最小效应不足以唯一确定备择，故暂不支持。PB 伪中心、非完整重复、裂区和区组设计不套用本合同。

给定基础模型矩阵 `X`、`N0` 个基础运行、重复数 `r` 和被检验系数 `β=δ/2`：

`ν = r*N0 - rank(X_r)`，`λ = (δ/2)^2 / (σ^2 * [(X_r'X_r)^-1]jj)`。

其中 `X_r` 是完整设计重复 `r` 次后的模型矩阵，`j` 是目标主效应列。功效为 `Pr(F(1,ν,λ) > F_(1,ν;1-alpha))`，用非中心 F 分布上尾计算。样本数反解按正整数重复数递增搜索，返回第一个达到目标的值，核对前一个值不达标，并限制总运行数不超过 10,000。无正误差自由度、模型项不满秩、输入越界或上限内无解时明确拒绝。

## Schema、工程与持久化

不新增 DOE 持久化字段，因此 Schema v5 足够；v1–v5 读取、迁移和坏元数据隔离合同不变。事件数/试验数及 Variability 测量列必须预先声明为 `response_names` 并通过现有 `column_map.responses` 映射；当前工作表列名摘要覆盖全部列，故分析不接受设计元数据创建后新增且未登记的列。计算使用当前表的深拷贝和现有 run_id 设计映射。结果不缓存到设计元数据、不写回原始响应、不改变 run_id、运行序或响应列。变异性摘要仅在结果窗口呈现；功效结果也是即时值。

任何当前工作表切换、运行身份/DOE 元数据校验失败或输入快照改变都会阻止继续计算/发布旧结论。H GUI 入口必须保持参数、取消、表格与适用图形路径；工程往返回归验证工作表原始列和 DOE 谱系，而不引入结果 schema。
