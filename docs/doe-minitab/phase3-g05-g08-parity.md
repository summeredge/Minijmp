## G06 多样本方差多重比较

| 字段 | 原生（phase4 multi_variance） | MiniJMP | 判定 |
|---|---|---|---|
| 95% Bonferroni 区间 A | (1.98865, 8.61111) | (1.98865, 8.61111) | PASS |

| 95% Bonferroni 区间 C | (2.06587, 8.37558) | (2.06587, 8.37558) | PASS |
| 单组置信水平 | 98.3333% | 98.3333% | PASS |
| 多重比较 p | 0.966 | 成对 Bonett 原始 p 0.886/0.544/0.766，Bonferroni 调整后均为 1.000 | 方法差异 |
| Levene p | 0.908 | 0.905（均值中心） | 见下 |

成对比较表逐行给出原始 p（单次对数比正态检验的双侧 p）、min(1, 3·原始 p) 的 Bonferroni 调整 p 及显著差异判定；三行均判为无显著差异，与 Bonferroni 联合区间不跨 1 的结论一致。

原生“多重比较 0.966”无法由归档字段反推唯一算法：成对 Bonett、F、Welch、Levene 两两比较经 Bonferroni 均给出 1.000 或更小值，均不等于 0.966，且原生未输出成对表。按 phase3-baseline 约定，MiniJMP 明确标注为自选 Bonett 对数近似成对比较，不声称等价，属 B 统计方法差异。

原生 Levene 0.908 与 MiniJMP 中位数中心 Brown–Forsythe 0.908 一致；MiniJMP 报告的均值中心 Levene 为 0.905，是既有独立方法，前次基线已记录，本次未改变。
