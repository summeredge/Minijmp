## 结论边界

- D-optimal 的最小案例由穷举证明端点组合 det=4；较大候选集只报告方法、目标值和停止原因。
- D-optimal 精确搜索需同时满足候选行数上限与组合数预算（`comb(n,count) ≤ 200000`）：20 选 10（184756）可穷举，21 选 10（352716）自动降级为启发式；`global_optimum_proven` 只标记真正完成穷举的结果。增补选择同样按组合数判定（30 选 15 直接降级），父设计运行固定不参与交换。
- 距离准则按“编码原点最远起点 + 逐步最远点”实现，只支持响应面；增补时父设计运行作为固定锚点参与最远点判定。选点后会按真正选中的运行重建模型矩阵，秩亏时拒绝生成设计（如二维完整二次模型选 3 点，秩 3/6）。轴点经 `coded_value` 编码，允许位于声明 low/high 之外；同一数值标为 factorial 仍拒绝。Mixture 距离合同依赖工作包 F，未开放 GUI。
- 混合 DSD 主效应可以相关（例如 4 连续 + 1 分类中分类列与连续列交叉积为 ±2）；核验条件是主效应与二因子交互正交且存在中心水平，不能据此拒绝已核验构造。
- 这些参考不构成 Minitab 产品输出或标准序一致性证明。
