# F3-1A 开发验收

## A1 非参数检验

入口为“统计 → 非参数检验”。计算位于 `code/nonparametric_tests.py`，列选择及 StatTable 报告位于 `code/sample_test_dialog.py`。符号、Wilcoxon 和 Mann–Whitney 支持三种备择，置信区间统一按双侧报告。

| 方法 | 定义及边界 | 验证 |
| --- | --- | --- |
| 符号 | 零差排除，正差数服从二项分布。中位数区间以全样本次序统计量构造。 | 独立二项系数、缺失、零差及实际覆盖率。 |
| Wilcoxon | 零差排除，并列绝对差取平均秩。无并列且有效数至多 50 采用精确法，其余采用含连续性修正的正态近似。位置估计来自 Walsh 平均值，要求对称分布。 | 独立枚举符号组合，并核对正负秩和、全零及并列。 |
| Mann–Whitney | 小样本无并列用精确 U，其余用含并列与连续性修正的正态近似。估计为第一组减第二组的成对差中位数，位置差解释要求平移模型。 | 独立枚举秩子集，核对 U、概率、差值区间及并列。 |
| Kruskal–Wallis | 合并秩 H 统计量，并列修正后使用卡方近似。 | 手算平均秩、修正项和卡方尾概率。 |
| Mood | 以合并中位数划分，等于中位数计入下侧，采用 Pearson 卡方。各组中位数报告次序统计量区间。 | 手算列联表和卡方，核对中位数相等的归类。 |
| Friedman | 完整区组内取秩，并列修正后使用卡方近似。 | 手算区组秩和、卡方概率，并拒绝重复与不完整区组。 |
| 游程 | 排除等于阈值和缺失观测，保留其余观测次序。小样本以二项组合数计算条件概率，大样本采用连续性修正。 | 独立枚举二值顺序，核对双尾概率和排序敏感性。 |

秩位置区间适用于无重复观测的连续位置模型。小样本按离散分布给出达到请求水平的保守区间，离散度不足时可无界。大样本使用正态近似。Walsh 平均值或成对差值最多生成 200 万项。卡方近似在小样本下须谨慎解读。

真实 Windows Tk 回归从七个菜单命令打开对话框、选列、确认并接收结构化报告。核心专项 7 项通过。菜单和 G12 清单回归通过，离线帮助调整项复验 14 项通过。

复用 [F3-1 审计](f3-1-feature-audit.md#原生证据与具体差异)的七种固定输入。历史记录证明 Minitab 19.1.0.1 返回结果对象，缺少各字段可读数值，当前常规安装路径及 COM 注册未找到对应程序。本地独立验证已通过，厂商的 p 值、估计与区间逐字段比较仍待补证。Minitab 的 Wilcoxon 和 Mann–Whitney 公开方法包含连续性修正的正态近似，本地小样本精确结果可能有差异。

## A2 项目工作表合并

入口为“工作表 → 合并项目工作表”。`code/worksheet_merge.py` 使用 pandas 合并源行号，按行号读取输出字段。两侧可分别选列，匹配键按各自工作表的列顺序配对。任一复合键分量缺失时不匹配，重复键保留全部组合。混合数值类型比较保留大整数精度。按行并列时较短一侧补缺失。重名列附加侧别或递增序号。结果创建为纯数据工作表，源表属性、公式和 DOE 数据保留在源表中。

`tests/test_worksheet_merge.py` 六项通过，涵盖四种连接、组合键、缺失键、日期、文本、大整数、重名列和不等长并列。真实 Tk 菜单验证预览、取消及确认，校验两张源表数据与属性不变。工程、帮助和菜单联合回归通过，G12 文件顺序调整后单独复验 15 项通过。

复用 Minitab 19.1 的重复键案例，得到按行并列 3 行 4 列、全外连接 6 行 4 列，其中 4 行为重复键组合、两侧各 1 行未匹配。原生组合键及缺失键选项无对照数据。

## A3 双样本离散度检验

入口为“统计 → 双样本离散度检验”。原始输入支持独立双列或数值列加二分类列，经典 F 另接受汇总样本量和标准差或方差。三种方法均支持方差及标准差比尺度、非单位假设值、左右侧及双侧备择。旧 `two_pop_var_test` 补上样本标签并复用原有多样本结果。

经典 F 用观测方差比除以假设方差比，按 F 分布求尾概率和反演区间。Bonett 在等量且每组至少六个观测时，以假设比下的合并峰度修正对数比标准误，反演得到近似区间。Levene 以组中位数绝对偏差为输入，将第二组偏差乘假设标准差比，按有符号合并 t 推断，双侧 t² 等于对应 ANOVA F。区间用同一有符号检验反演。多样本检验原计算保持原有方法。

`tests/test_variance_ratio.py` 以不完全 Beta 函数验证 F 概率，以分位反演验证方向和区间，以 SciPy 中位数 Levene 和非单位比缩放参考验证 Levene。Bonett 区间端点回代检查尾概率。真实 Tk 验证菜单打开、原始双列 Bonett 和结构化报告。

Minitab 19.1 固定案例的比值为 0.762069。本地 Bonett p=0.536612、区间 (0.280663, 2.044317)，历史原生 p=0.536、区间 (0.281, 2.042)，存在轻微差异。本地 Levene p=0.559034、区间 (0.258530, 2.134600)，与历史原生显示值一致。Bonett 的不等样本量推断仍待扩展。[厂商方法](https://support.minitab.com/en-us/minitab/help-and-how-to/statistics/basic-statistics/how-to/2-variances/methods-and-formulas/methods-and-formulas/) · [Bonett 方法论文](https://support.minitab.com/en-us/minitab/media/pdfs/translate/Bonetts_Method_Two_Variances.pdf)

## A4 基础等效性检验

入口为“统计 → 等效性检验”，提供单样本、双独立样本及配对三项。复用 `code/t_test.py` 的单样本、Welch 及等方差 t 推断，以同行有效配对差计算配对检验。单样本可设目标值，双样本可反转差值方向。上下等效界限可不对称，须事先确定。

两项单侧备择分别为大于下限及小于上限，整体 p 为两项中较大值，两项均小于 α 时判定等效。区间使用 1−2α 的双侧覆盖率。图形展示等效范围、估计差及对应区间。报告另外标出区间完全落在等效界限外的情况。

`tests/test_equivalence.py` 与独立 t 分布及 statsmodels 单双侧概率、Welch 自由度和配对结果一致，覆盖界限附近、区间落在界限外及证据不足。真实 Tk 三个菜单分别验证报告及区间图。历史 Minitab 19 TOST 只有命令对象，未取得可读数值。2×2 交叉和专用生物等效模型不在本轮范围。[TOST 定义](https://support.sas.com/documentation/cdl/en/statug/66103/HTML/default/statug_ttest_details19.htm)

## A5 工程结果持久化

现有 `.dexpl` ZIP/JSON/Parquet 工程增加可选结果字段和编号 PNG 成员。结构化结果保存原报告文字、列、数值、显示值和数字格式。图形保存确认或存档时的 Matplotlib 快照，不读取可执行对象。保留活动工作表及分析发布顺序。来源重命名随表更新，来源删除后记录保留原名称并标为已删除。编辑数据不改动历史结果。

重新打开后，“视图 → 查看统计结果”可按当前表查看快照并导出 TXT 或统计表 Excel；“图形”菜单可查看恢复图形、另存图片或导出 PDF。恢复图形为只读内容快照，图形对象状态以及 Plotly 图窗不写入工程。旧工程缺少结果字段时按空历史打开。工程写入仍经同目录临时文件及原子替换。读取时拒绝不合法的表结构、路径和损坏图形。

`tests/test_worksheets.py` 增加双工作表、多报告、多图形、活动表、源数据修改、改名、删除及 TXT/XLSX/PNG 导出往返。另验证坏图形在替换当前工程前被拒绝。保留旧工程、原子保存、公式和 DOE 的既有检查。

工程、来源上下文与图窗生命周期回归 88 项通过。添加往返、损坏文件和保存保护检查后，相关工程、菜单、帮助与清单定向核验 63 项通过。
