# MiniJMP 功能缺口与 F2 开发顺序

基于 [覆盖矩阵](coverage-matrix.csv)。下表 ID 省略统一的 `F0-` 前缀，DOE ID 原样保留。P0 优先处理高价值工业质量与常用模型缺口，P1 补齐高复用扩展，P2 暂缓专业场景或产品表现差异。官方文档支持立项，实机 GUI 路径、默认值与可选项仍需核验。开发验收以独立参考和 MiniJMP 正常入口为准。

| 优先级／工作包 | ID、状态与 Minitab 对应功能 | 最小实现及验收 | 模块、依赖与复杂度 |
| --- | --- | --- | --- |
| **P0 · Q1 属性过程能力** | NEW-029 未实现。Capability Analysis 的 Binomial / Poisson | 先做二项。输入各组不合格品数和样本量，输出比例、区间、PPM、过程 Z 及诊断；验收覆盖等长／不等长、全零、非法计数。二项验收后再做按单位缺陷率和暴露量的泊松分支。 | 复用 P/U 图、比率区间与过程能力报告；泊松分支的官方选项需单独确认。高 |
| **P0 · S1 泊松率推断** | NEW-025 未实现。Basic Statistics 的 1-/2-Sample Poisson Rate | 交付计数与暴露量输入、率和率差、区间及检验。独立校验零事件、不同暴露量、单双侧和合并估计的适用条件。 | 复用基本统计对话框与比率报告；精确与近似方法分别验收。中 |
| **P0 · M1 固定效应一般线性模型** | NEW-027 部分实现。ANOVA 的 Fit General Linear Model | 连续响应、多个固定因子及协变量、显式主效应和交互项；验收非平衡、秩亏、缺失和 PRESS。旧双因子路径保持既有结果。 | 复用 anova_2way 与 advanced_regression；先锁定平方和和可估性规则。高 |
| P1 · Q2 量具与子组 SPC | NEW-028 未实现，Type 1 Gage Study / Gage Linearity and Bias；BASE-051 部分实现，EWMA / CUSUM | 第一批做单标准件偏倚、Cg/Cgk 和运行图；第二批核验多标准件线性和子组平滑图。验收覆盖零变差、标准值、子组大小及外部基线。 | 复用量具图形与 advanced_spc；子组方法和多标准件选项需补证。高 |
| P1 · S2 基础推断选项与功效 | BASE-003、BASE-025 部分实现，Normality Test / Equal Variances；NEW-026 未实现，Power and Sample Size | 先做非 DOE 的一、双样本 t 功效及样本量反解，校验最小整数解。补正态性方法和全局方差检验前先落实分布假设、选项及独立参考。 | 复用基本统计菜单和 doe_power 的输入/求根模式；后两组厂商选项待补证。高 |
| P1 · T1 时间序列扩展 | BASE-017 部分实现，Time Series 的平滑与分解 | 先移动平均和简单指数平滑，后续核验 Winters 和分解。独立递推验收初值、缺失行为、预测索引和预报。 | 复用 time_series_analysis 和现有对话框；厂商初始值选项待补证。中 |
| P1 · D1 逆堆叠与 Calc | NEW-006 部分实现，Unstack Columns；NEW-008、NEW-009 未实现，Random Data / Sample From Columns / Probability Distributions | 保留组内原序与不等长列；实现固定种子抽样及常用正态、二项、泊松概率／逆概率；验收重复标签、缺失、边界概率和当前表存储。 | 复用 modified_table、工作表状态及 SciPy；再核实厂商存储选项。中 |
| P2 · Q3 罕见事件图 | NEW-031 未实现，G/T | 先 G 图，验收日期、机会数、until/between 和控制限；T 图在持续时间模型范围确认后实施。 | 复用 SPC 输出与日期转换；T 对话框待核。高 |
| P2 · G1 实时绘图预览 | NEW-038 部分实现，Graph Builder | 在通用绘图器加入候选图型和变量变化后的预览；验收切表、取消及缺失值。 | 复用 plot_selected；依赖渲染生命周期核验。中 |
| P2 · DOE 扩展 | SCR-002、FAC-012 部分实现，DSD / Fold Design | 按专项验收 ID 扩展有需求的分类组合与 Foldover 配置；验收设计规模、秩、别名及已有配置回归。 | 复用 doe_dsd 和 DOE 因子设计管线；先核定合法配置，保留 E02。高 |

**F2 首包执行 Q1 的二项能力。** 它补上离散质量数据从监控到能力评估的缺口，可复用 P 图和现有比率区间。先锁定报告字段、分母校验与零事件语义，随后再引入泊松暴露量。接下来执行 S1、M1。

## 验证待办

- **E01、G08、G03、G07。** 分别保留 Binary RSM Wald z 尾差、DSD 构造等价性、BASE-005 参数 SE/CI 原生输出、BASE-045 非参数容差取秩的历史结论。维护数值及方法证据栏；只有验证出影响用户结果的具体差异才新增算法任务。
