## 源码 ZIP 边界

`tools/make_zip.py stage-source` 以磁盘源码为输入，以保留未跟踪但必需的源码工具；因此不能仅依赖 Git 跟踪状态。源码暂存增加精确排除：本机 `PIReader/config.txt`、三项本机 OSIsoft SDK DLL、`.env`/`local_settings.py`、常见日志和临时后缀、草稿截图、版本化构建日志、`docs/_build/` 与 `PIReader/.vs/`。运行包仍由原发布脚本组装，并继续使用本机构建所需的配置和授权依赖。

打包专项在临时测试目录生成源码 ZIP，验证上述排除项不进入归档，同时保留普通图片、CSV 夹具、PIReader 源文件及根目录构建说明。没有在项目 `dist/` 生成发布 ZIP；`dist/` 当前为空并保留。
