# MiniJMP V1.1 安装与使用说明

> 本说明面向内部审核与 Windows x64 用户；不表示已完成企业现场验收或合规放行。许可状态见 [版本与审核说明](VERSION-INFO.md)。

## 安装要求与目录

- 目标为 64 位 Windows 桌面环境。当前发布资料未声明最低 Windows 版本；不要据此推定旧版 Windows 已验证。
- 取得 `MiniJMP-V1.1-Windows-x64.zip` 后，先按随包 `SHA256SUMS.txt` 校验哈希。
- 将 ZIP 完整解压到用户可读取和执行的位置，保持目录结构。运行目录至少包含：

  ```text
  MiniJMP.exe
  _internal/                 Python、Tk 和程序依赖
  PIReader/                  PIReader.exe、三个 SDK DLL、干净 config.txt 与 tags.txt 模板
  BUILD-INFO.txt             本次构建信息
  SOURCE-CODE.txt            对应源码包说明
  THIRD-PARTY-NOTICES.txt
  THIRD-PARTY-LICENSES/
  ```

- 双击 `MiniJMP.exe` 启动。不要单独移动 EXE 或 `_internal`。无需另装 Python、无需安装程序或管理员权限；当前用户需能写入下述偏好、配置和日志目录，以及所选工作文件目录。

## 文件与用户设置位置

- 应用偏好 `app.json`（当前 MiniJMP 不保留最近文件路径）：`%USERPROFILE%\.dataexplore\app.json`。
- 冻结版表格默认配置 `default.conf`：`%LOCALAPPDATA%\MiniJMP\user_config\default.conf`。这是表格组件配置，不是 `app.json` 的位置。
- 错误日志：`%LOCALAPPDATA%\MiniJMP\log\error.log`。
- PIReader 与 PI 配置文件的路径偏好：`HKCU\Software\MiniJMP\PIImport`；只保存路径，不保存凭据。
- 工程、导入文件和导出文件位于用户选择的位置。请按组织要求限制文件权限并备份。

## 常用操作

1. **导入 CSV/文本：**选择“文件 → 导入 CSV”，选取 `.csv`、`.tsv` 或 `.txt`。若程序要求确认，检查预览中的编码、分隔符和首行表头，再确认导入。需要手动指定解析选项时使用“文件 → 高级导入”。
2. **导入 Excel：**选择“文件 → 导入 Excel”，打开 `.xlsx` 或 `.xls` 工作簿；其中各个工作表会导入为 MiniJMP 工作表。HDF5 暂不可导入，请先在来源程序中导出为 CSV 或 Excel。
3. **统计分析：**切换到要分析的工作表，选择“统计 → 描述性统计”或相应检验/回归菜单，在参数窗口选择列和选项后运行。结果显示在分析结果窗口或表格中；统计假设和方法限制请查看对应帮助。
4. **绘图：**选择“图形 → 直方图与分布拟合”“图形 → 散点图”等入口，在窗口指定数据列和图形选项并生成图形。可用“图形 → 保存图形”将当前图形保留在应用中。
5. **保存及重开项目：**首次保存选“文件 → 另存为”，保存为 `.dexpl`；后续使用“文件 → 保存”。重开时选“文件 → 打开项目”并选择该 `.dexpl`。导入的 CSV/Excel 工作表在项目保存后随项目状态保留；随包示例工程也可从“打开项目”窗口选择。
6. **导出：**“文件 → 导出当前表（单表 / Excel）”可将当前工作表保存为 `.csv` 或 `.xlsx`；“文件 → 导出 CSV”可导出 CSV。多工作表项目请保存为 `.dexpl`，不要用单表导出代替项目保存。
7. **帮助：**选择“帮助 → 帮助文档”或按 `F1` 打开本地离线帮助；分析窗口可用其帮助入口查看对应说明。用户点击在线延伸阅读或许可链接时会调用默认浏览器。
8. **退出：**选择“文件 → 退出”或关闭主窗口。若项目有未保存修改，按提示保存或确认放弃后退出。

## 文件安全、联网与 PI

- 当前 `.dexpl` 工程使用版本化 JSON 元数据和 Parquet 表格数据，不使用 pickle。当前版本拒绝打开旧版 pickle 工程和 `.pickle` 单表文件；需要迁移历史工程时，请联系公司 IT 制定隔离环境迁移方案，不要在普通环境打开旧版文件。
- MiniJMP 不安装 Windows 服务或监听端口。在线文档等外部页面在用户点击后由浏览器打开；PI 网络访问只在用户启动 PI 导入时经外部工具发生。本说明不是网络抓包或企业防火墙验证。
MiniJMP V1.1 Windows 发布包随附三个 PI SDK 相关组件，用于支持 PI 数据访问。PI 数据导入功能须在已取得相应授权、安装并正确配置 PI SDK/PIPC 运行环境，且具有 PI Server 访问权限的企业办公终端上使用。随包组件不构成完整的 PI System 运行环境，也不代表授予额外的软件使用或再分发许可。 三个 DLL 保持专有第三方身份，再分发授权待企业确认；公开 Git 与源码 ZIP 不含 SDK DLL，不自动安装或注册组件。
- Defender/EDR、DLP、组织代理、普通用户权限及实际 PI Server 连通性，均须由目标环境单独验收；本说明不宣称已完成这些验证。

未使用PI时，CSV/Excel本地分析、项目保存与随包帮助可离线使用，不需要部署服务端。统计结果可在结果窗口导出或复制；图表可用图窗工具栏保存按钮导出为图片。旧工程应先保留备份，仅打开可信来源文件，旧版本格式兼容性未在企业现场逐一验证。


V1.1 导入资源与路径要求

- 文件不超过 256 MiB；单表不超过 200 万行、16384 列，各表总计不超过 1000 万单元格。多表文件最多 256 张表；ZIP 容器最多 4096 项、解压后总计 512 MiB；工程 manifest 最大 16 MiB。解析后的表格数据总内存上限 1 GiB。这些上限不是全部进程内存承诺；导入有额外解析开销。超限请按行/表拆分，不会替换当前工作表。
- 完整解压到不超过 80 个字符的本地受控运行目录，例如 C:\Apps\MiniJMP-V1.1；构建仓库路径同样不超过 80 个字符。程序会提示过长的运行目录。正式运行包检查各文件路径与 80 字符安装目录的合计不超过 240 字符；不依赖系统长路径开关，解压前由 IT 确认目标路径。
- 安装目录须由 IT 设置为普通用户只读，禁止从下载目录或多人可写共享盘运行。PIReader 固定路径并不防止文件被替换；部署方须在首次运行及更新前核验全包 SHA256SUMS，并使用 EDR 持续监控 EXE/DLL/PYD 的基线完整性。启动前的完整性替代控制须由 IT 审批及留存证据，当前应用没有签名/哈希自校验。

增量 CSV、Excel XML 预检及 Parquet 批次解析设 60 秒协作式时间预算；在下一记录/批次检查并拒绝。底层 pandas、xlrd、Arrow 的单次调用无法在同步入口中强制中断，不保证严格的 60 秒进程级超时；文件/展开尺寸和批次资源限制用于减少大文件阻塞。
