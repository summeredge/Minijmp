# MiniJMP v0.1.0-beta.4 — pandas 3.0.6 兼容性与数据完整性增强

## 版本与范围

产品版本 `v0.1.0-beta.4`，Windows 发布包标识 `V0.1-beta4`，EXE 资源文件版本 `0.1.0.4`。beta.3 原始基线为 `d21a924abf6f437f82e2736ac09c5a38dc636d5f`；pandas 迁移成果提交为 `d321c59806230572bc6d7ba2c752ad8c80a62891`。本版不新增菜单、统计方法或绘图类型。

## 主要变化

- 正式 pandas 依赖统一为 3.0.6，Python 3.11 发布环境使用锁定依赖。
- 工作表对整数、字符串、布尔、日期和缺失值的处理更加安全；批量编辑、粘贴、填充和清除无法安全转换时拒绝部分写入。
- CSV 和 Excel 导入保护大整数、高精度小数与带前导零的标识符；`.xlsx` 支持恢复读取器舍入的原始数值文本。
- PIReader 保留数据状态及大整数精度；修正 PI 时间频率与 pandas 的兼容性。
- 修复旧 pandas API、统计处理与分类分组的兼容问题，保留原有统计方法和分组语义。
- 通用绘图器的保存 DPI 不再改变其他统计图的全局导出设置。

## 验证与限制

迁移完成后的项目 `.venv` 全量回归记录为 **3810 passed、0 failed、0 skipped、120 warnings**；详细分项、历史 AST 守卫和环境证据见 [pandas 迁移报告](pandas3-migration-report.md)。此结果针对迁移源码，不能代替 Windows 发布包验收。

`.xls` 的双精度存储无法恢复已经丢失的超精度原始数值，标识符应使用文本单元格。PI 测试使用合成数据，尚未连接实际 PI Server；外部用户工程文件尚未人工抽样。实际 EXE/ZIP、目标办公电脑的 Defender、DLP、普通用户权限与 PI SDK/Server 验收状态以项目工作记忆和执行日志为准；未完成检查不得视为通过。beta.3 历史范围保留在 [原基线记录](v0.1.0-beta.3-baseline.md)。
