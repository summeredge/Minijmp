# MiniJMP V1.1 源码准备

V1.1 / v1.1.0 / 1.1.0.0 是安全整改复审版本，不增加统计功能。历史 Tag 与发布包不覆盖。

- 使用 `tools/release_metadata.py` 检查主程序、PIReader、构建及当前说明的版本一致性。
- 正式构建沿用 `tools/build_windows_release.ps1`；依赖版本锁及 SHA-256 wheel 锁、源码编译 PIReader、双 EXE 可信签名、实际运行目录 SBOM、DLP 检查和 ZIP 摘要都保留。
- 导入资源限制见 `packaging/windows/USAGE.txt`；支持离线帮助，超限导入保留已有工作表。
- `.agent-memory/` 和 `.stage/` 不进入发布压缩包；受限审查材料应存放在仓库之外，不纳入公开源码包。
- 正式构建前须具备可用的 .NET Framework 4.8 参考程序集、合法 PI SDK 编译引用和可信代码签名证书。未满足时只交付明确标识的源码准备资料，不创建正式 Tag 或冒充已验收运行包。
- 本地源码依赖 SBOM 仅描述源码/构建输入，不能替代运行包实际收集清单、全量 SCA 和现场验收证据。
