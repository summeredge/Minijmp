完整回归分析

建模、诊断与预测 · Poisson 回归 · 名义 Logistic · 有序 Logistic · PLS 回归

建模、诊断与预测

入口：统计 → 完整回归分析；Poisson 回归、名义 Logistic 回归、有序 Logistic 回归及 PLS 回归菜单预置同一窗口的模型类型。原有 OLS、WLS、二元 Logistic、非线性、线性回归、残差图和正交回归入口保留。以下介绍各模型的统计约定；训练集拟合良好不等于通过独立预测验证。

变量选择与操作

  1. 选择响应 Y，用 Ctrl / Shift 多选解释变量 X；PLS 可选择多个数值响应。在右侧列表选择需要分类编码的 X；分类列应同时属于所选 X，PLS 的 X 仅接受数值列。
  2. 选择模型类型。WLS 另选权重列；Poisson 选择链接函数；名义 Logistic 明确响应参考类别；有序 Logistic 明确响应从低到高的完整顺序；PLS 设置中心化/标准化、成分数与交叉验证。适用模型可选择多项式次数及两两交互项；这些是模型项设置，不是自动寻找最佳模型的保证。
  3. 按需选择变量筛选、筛选准则、置信水平与缺失值策略。非线性选择曲线或填写公式及参数初值。点击“建立模型”；后台计算时可“取消计算”，当前求解步骤返回后丢弃取消结果。
  4. 结果通过模型摘要、系数、方差分析、残差诊断、共线性诊断、观测诊断、模型比较及适用的分类评估、ROC 页面查看。关闭“输出诊断页面”仅控制页面展示。
  5. 选择“预测数据工作表”并点击“预测”，查看“新数据预测”。“当前表写入新工作表”和“导出当前表”作用于当前选中的结果页，支持 Excel / CSV；“输出完整报告”发送训练模型的报告到来源工作表的结果窗口。
  6. 切换到独立的“图形”页，在下拉框选择图形类型并点击“打开图形”；图窗沿用现有图形保存功能。窗口“帮助”及 F1 打开本页。

数据、源行号与分类变量

分析使用打开窗口时来源工作表的快照；切换工作表不会把已有模型改绑到另一张表。源行号是快照中的位置编号，从 1 开始，与 DataFrame 索引标签分开；删除不完整行后仍保留原位置，不能重新按有效样本编号。图中的观测拾取按源行号定位；来源数据已更改或来源工作表已删除时应重新建立分析，避免选中错误行。

缺失值默认“报错”；明确选择“删除不完整行”后才对本次模型所需的 Y、X、权重联合删除，并报告使用和删除的样本数。不自动插值、填补或将缺失值改为零。非有限数、无效权重、常量解释变量、完全共线性、奇异矩阵及残差自由度不足应给出明确错误。多模型比较必须使用相同的有效样本。

分类编码采用训练时确定的水平和参考水平；截距下的系数表示相对参考水平的差异，交互项会改变主效应的条件解释。预测必须复用训练模型项和类别编码，不能重新选参考类别。新数据缺少必需列、出现未知类别或无效数值时应明确报错，不静默按参考类别处理。Logistic 的响应编码和事件类别须以实际报告为准。

OLS 与模型项

普通最小二乘模型为 y = Xβ + ε，以最小化 SSE = Σ(yᵢ − ŷᵢ)² 估计系数。X 包括截距、数值项、分类编码、多项式项和交互项。多项式是自变量的幂，不是改变响应变量；交互项描述一个变量的作用随另一个变量变化。解释高次或交互系数时需同时保留其低阶项。

系数表给出估计值、标准误、t 统计量、双侧 p 值和置信区间。设有效样本数 n、设计矩阵秩 p（含截距），残差自由度为 n − p。均方根误差 RMSE = √(SSE/n)，残差标准差 S = √(SSE/(n − p))，两者分别报告。有截距时 R² = 1 − SSE/SST，SST = Σ(yᵢ − ȳ)²；调整 R² = 1 − (1 − R²)(n − 1)/(n − p)。这些值反映样本内拟合，不代表新数据预测能力。

适用的 ANOVA 表分解回归与残差平方和、自由度及均方；总体 F 检验针对非截距系数同时为零的原假设。它不是每个变量的顺序平方和检验，也不是非线性或 Logistic 的通用报告。

WLS 权重与白化诊断

加权最小二乘最小化 Σwᵢ(yᵢ − ŷᵢ)²。权重必须严格为正且有限，权重为误差方差的倒数：Var(εᵢ) = σ²/wᵢ；不是标准差倒数、频数或优先级。若已知标准差 sᵢ，应输入 1/sᵢ²。权重仅规定相对方差；错误的权重会使区间与诊断失真。

白化数据为 X* = √W X、y* = √W y、e* = √W(y − ŷ)。WLS 的协方差、尺度估计、杠杆值、Cook 距离和残差检验应基于白化空间；原始残差保留用于数据量纲解释。加权残差均方为 Σwᵢeᵢ²/(n − p)；有截距的加权 R² 使用加权均值构造总平方和。报告应区分加权 RMSE 和原始单位的误差汇总。

WLS 的新观测预测区间需要新样本的权重以确定 σ²/w新；不能把原始尺度的预测误差默认视为同方差。均值置信区间只描述拟合均值的不确定性。白化异方差检验用于检查权重模型是否仍留下系统性的方差变化。

Logistic 二元回归

模型 log(p/(1 − p)) = Xβ，p 为指定事件发生概率，采用二项似然估计。系数表给出标准误、Wald z、p 值及相应区间；exp(β) 为条件优势比，不是概率比。概率预测及其区间限制在 [0, 1]；概率区间通常先在 logit 尺度计算再反变换，不是二元新观测的连续预测区间。

Logistic 不使用 OLS R²、调整 R²、OLS RMSE 或 OLS ANOVA。适用指标包括对数似然、偏差、伪 R²（必须注明具体定义）、AIC、BIC及分类评估。McFadden 伪 R² = 1 − log L模型/log L仅截距，不能解释为方差解释比例。

混淆矩阵、准确率、精确率、召回率和特异度依赖分类阈值；ROC 随阈值变化描绘假阳性率与真阳性率，AUC 评价排序区分能力。训练集分类评估和 ROC/AUC 可能乐观，不是独立验证。类别极度不平衡时仅看准确率会误导；完全分离、不收敛、单一响应类别应报告失败，不能输出看似可靠的推断。

Poisson 回归：计数响应

Y 必须是有限的非负整数，允许零；连续 X 和分类 X 可组成多项式、交互模型项。模型假定条件均值与条件方差相同：Yᵢ | Xᵢ ~ Poisson(μᵢ)。链接为 log（默认，log μ = Xβ）、sqrt（√μ = Xβ）或 identity（μ = Xβ）。训练和预测均要求 μ 严格为正且链接域有效；sqrt 的线性预测量须为正，不能把负值平方后视为合法预测，identity 也不能输出零或负均值。

系数表给出估计、SE、Wald z、双侧 p 值及渐近 Wald 置信区间。log 链接下 exp(β) 表示其他项固定时的条件均值倍数；sqrt 和 identity 系数不能作此解释。预测给出条件均值及其近似置信区间。sqrt/identity 的均值区间先将线性预测量区间 η ± zSE 与 [0,∞) 取交集，再反变换；下界可为 0，属于均值区间的闭包边界，不改变预测本身 η 必须严格为正的要求，报告 notes 会明确说明此约定。conditional_lower/upper 为固定拟合均值下的 Poisson 计数分位数，不含参数估计不确定性。均值区间与条件计数分位数都不能称为包含全部不确定性的单次新观测预测区间。

报告使用对数似然、Deviance（偏差）、Pearson χ²、AIC/BIC 和残差自由度，不使用 OLS ANOVA、调整 R²或 OLS 正态残差推断。Deviance/Pearson 的拟合优度 p 值是 χ²渐近近似；稀疏计数、小拟合均值或样本不足时可能不可靠。Pearson χ²/残差自由度明显大于 1 提示过度离散，应核查遗漏因素、相关性和零值结构；提示不会自动改成负二项模型、调整协方差或证明模型有效。

诊断结合 Pearson/偏差残差与拟合值、来源行顺序及影响点；离散响应不要求原始残差正态。本次 Poisson 不接受权重或变量筛选，选择这些选项应明确报错。非典范链接的标准误受协方差约定影响，不能据软件名称假定与 Minitab 完全相同。

名义多分类 Logistic：无序类别

Y 至少有 3 个无序类别，必须明确响应参考类别 r；它与分类 X 的参考水平是两种不同设置。对每个非参考类别 k 拟合 log[P(Y=k)/P(Y=r)] = Xβₖ。参考类别的线性预测量设为零，通过 softmax 同时计算全部 K 类概率；每行概率应有限、位于 [0,1] 且总和为 1。分类预测取概率最大的类别，不把二元模型的 0.5 阈值逐类套用。

训练时固定响应类别顺序、参考类别和分类预测量的所有水平；预测复用原编码，不能因新表行序、缺少某个训练类别或类别出现顺序改变而重编码。未知预测因子水平、评估响应含训练未见类别、缺列、秩亏、不可识别、分离或未收敛应明确报错，不以静默正则化代替已指定模型。

系数及适用的 Wald 推断按“类别 k 相对参考类别 r”输出。报告包含似然/拟合评估、全部类别概率、预测类别、混淆矩阵及对数损失；对数损失为 −Σlog P(Yᵢ=实际类别)/n，越小越好。诊断使用类别概率和分类错误，类别编号只是标签，不能当连续观测值计算 OLS 残差。训练混淆矩阵不是独立验证；本次不把二元 ROC/AUC 当作多类诊断，也不接受变量筛选或权重。

有序 Logistic：明确顺序的类别

Y 至少有 3 类，必须给出从低到高的完整顺序，例如“低、中、高”；顺序必须不重复、不遗漏且不含额外类别，不按字母、数字大小或首次出现顺序猜测。模型采用共享斜率的累积链接形式 P(Y ≤ k | X) = F(cₖ − Xβ)，切点 c₁ < … < cₖ₋₁。logit 使用 Logistic 分布 F；probit（normit）使用标准正态分布 F，适用于潜在连续正态变量被阈值分组的解释。

logit 的共享斜率构成比例优势假设：各累积二分的回归效应相同；按本页符号约定，正 β 倾向更高类别，较低类别累积优势乘以 exp(−β)。probit 共享斜率不解释为优势比。Minitab 另提供 gompit，即 complementary log-log（互补双对数）链接 log[−log(1−p)]，它是不对称链接，并非 log-log。本次只实现 logit 与 probit。

报告分别列出回归系数及实际切点；求解器内部用于保证切点递增的变换参数不是实际切点，也不能将其标准误直接标作实际切点的区间。各类概率由相邻累积概率之差得到，首尾分别以 0、1 为界；须校验切点递增、累积概率单调、类别概率有效且行和为 1。

拟合评估、类别概率、混淆矩阵及对数损失可帮助检查预测。本次没有实现比例优势假设检验；收敛、似然改善或预测准确不能证明假设成立。效应随阈值明显变化时应重新考虑模型。类别反转会改变系数方向；比较其他软件时先对齐累积事件与符号。分离、不可识别及未收敛应报错，本次不接受变量筛选或权重。

PLS 回归：单响应与多响应

偏最小二乘 PLS 接受数值 X 和单个或多个数值 Y，使用 NIPALS（非线性迭代偏最小二乘）提取与响应相关的潜变量。X/Y 先中心化，可选择标准化；标准化及其均值/尺度从训练数据估计，预测复用训练变换并还原响应单位。PLS 可用于高度共线或特征数大于样本数的情形，但常量列、无效数值、成分超限或剩余有效秩不足仍须明确处理，不能认为成分越多越好。

选择固定成分或利用 K-fold / LOO（留一法）交叉验证比较成分数。K-fold 按输入行顺序连续分折，LOO 每次留一行；不是时间序列向前验证或分组验证。每折独立估计中心、尺度和潜变量，只对被留出的行预测，不能先对全表标准化后再分折。成分上限同时受训练样本数、X 维数和各折有效秩约束。CV 表及误差曲线比较各成分数的 PRESS（留出预测误差平方和），本次将留出残差除以相应训练折 Y 的样本标准差，再对全部行和响应取平方均值，按此最小归一 PRESS 选成分，并列取较少成分；该规则用于减小量纲支配，不保证与 Minitab 自动选出相同成分。未进行 CV 时不能将训练误差标成 PRESS。

结果包含 X/Y scores（得分）、loadings（载荷）、回归系数、解释方差、VIP（变量投影重要性）、训练预测与可用的 CV 误差。解释方差描述训练分解，VIP 是所拟合 PLS 模型中的相对贡献，VIP 大于 1 只是常见经验线；本次不提供 PLS 系数置信区间或 VIP 显著性检验。多 Y 联合建模与分别拟合每个 Y 不等价。

在“预测数据工作表”选择外部工作表可做留出预测；同名 X 必须齐全且合法。外部表包含训练模型对应的 Y 时可评估预测误差，没有 Y 时仅输出预测，不能编造误差指标。训练误差、选成分使用的 CV 误差和未参与调参的外部留出误差应分别解释；用同一 CV 选择成分并报告最小误差仍可能乐观。PLS 不接受分类 X、变量筛选或权重。

非线性回归与自定义公式

非线性模型 y = f(x, θ) + ε，通过非线性最小二乘估计参数。GUI 提供指数曲线 a*exp(b*x)+c、幂曲线 a*x**b、S 形曲线 a/(1+exp(-b*(x-c)))，也可填写受支持的自定义公式。x 表示选定的解释变量，a、b、c 等参数必须提供与公式一致的初值，例如 a=1,b=0.1,c=0。公式只用于受限数学表达式，不能执行 Python 语句、导入模块或访问属性。

初值、数据范围和参数可辨识性会影响收敛；幂、对数和指数等函数有各自的定义域与溢出限制。求解失败、非有限预测、奇异局部 Jacobian 或不足的残差自由度必须明确提示。收敛不保证找到全局最优解。

参数协方差与置信区间由最优点附近的 Jacobian 局部线性化得到，属于渐近近似区间；预测均值区间使用 delta 方法，新观测区间另计误差方差。强非线性、小样本、边界解或参数高度相关时近似可能较差。本阶段不提供 bootstrap 或轮廓似然区间。描述性的 R²/RMSE 可辅助查看拟合，但不能据此套用 OLS 的 ANOVA、精确 t/F 推断或调整 R²解释。

变量筛选、最佳子集与模型比较

前进筛选从较小模型加入候选项，后退筛选从较大模型移除候选项，双向筛选交替考虑加入与移除；按选定准则改善模型，具体允许的组合及层级约束以计算报告为准。分类变量应作为一个完整项进行筛选。最佳子集在允许的候选项集合中枚举比较，组合数随候选项数指数增长，因此必须设置有限搜索规模；超限应明确报错，不能无提示改成另一种筛选方法。

AIC = −2 log L + 2k，BIC = −2 log L + k log n，k 为该模型实现所计的参数数；两者越小越好，调整 R²越大越好。不同响应变换、样本集合、权重定义或不相容的似然之间不能直接比较这些值。小的准则差异并不证明唯一最优；模型比较页面和图形展示的是实际拟合的候选模型。

逐步回归和最佳子集后的推断存在选择偏差。常规系数 p 值、置信区间和预测区间通常以模型事先固定为条件，没有校正反复筛选的不确定性；不能当作已作选择校正的确证性结论。本次新增的 CV 仅适用于 PLS；不能因此把旧模型的样本内“最佳”指标称为已验证的泛化性能。

诊断、异常观测与可视化

VIFⱼ = 1/(1 − Rⱼ²)，其中 Rⱼ² 来自将该设计矩阵列对其他列作辅助回归；不解释截距的 VIF。分类及多项式展开后的单列 VIF不是整项的广义 VIF，高 VIF 提示不稳定性但不是自动删变量的理由。

OLS/WLS 适用的残差正态性检验与 QQ 图检查误差形状；异方差检验检查条件方差，自相关诊断（如 Durbin–Watson）检查观测顺序下的相关性，DW 约为 2 表示没有明显一阶相关的线索。Poisson 和类别响应不使用 OLS 正态残差检验。残差顺序使用有效观测的来源顺序，未经时间列验证不能将其当作等间隔时间。各检验有样本量和模型适用条件；未拒绝原假设不等于假设已被证明。

OLS/WLS 杠杆值 hᵢ 是相应帽子矩阵的对角元。Cook 距离综合残差大小和杠杆值衡量删去观测后的影响；本模块以 |内部标准化残差| > 2、hᵢ > 2p/n、Cook D > 4/n 标记。它们仅为探索性筛查，不是经过多重性校正的异常检验。异常点需结合录入、工艺和模型假设核查，不自动删除。Logistic 采用标准化 Pearson 残差及 GLM 一阶 Cook 近似，不提供正态残差 QQ 图；非线性采用局部 Jacobian 的一阶近似影响量。

按模型选择适用图形：连续响应实测与预测、残差与拟合值/序列、适用的影响诊断与系数区间；二元 Logistic ROC；多类别概率和混淆矩阵；PLS 成分选择误差曲线、得分、载荷和 VIP。没有区间的 PLS 系数不能画成置信区间。置信区间图表示参数或均值不确定性；预测区间针对新观测，通常更宽。多变量预测图随展示轴和其他变量的设定变化，不能视为单一 X 的无条件因果曲线。观测图保留源行号，点击样本可定位来源观测。

结果保存与当前边界

观测诊断和预测页保留源行号、预测值及适用的残差、区间、影响量或分类结果。新数据预测的行号属于预测数据快照；不得用于定位训练表的同号行。结果表可写入新工作表，原表不覆盖；Excel / CSV 保存原始数值，显示格式不应截断导出精度。统计报告经 StatTable 展示和输出，图形复用现有图窗。

计算在后台执行；点击“取消计算”后，当前求解步骤返回时丢弃该任务的迟到结果，保留上次有效模型和图形，不表示立即强行终止底层求解器。训练与预测保持各自数据快照和源行号，图形、报告及写入结果绑定来源工作表；切换活动表不会改写模型来源。缺失处理始终沿用明确选定的策略，不自动填补。
