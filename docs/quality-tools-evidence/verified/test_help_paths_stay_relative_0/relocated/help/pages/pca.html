建模、监控与选区分析

入口：统计 → 主成分分析。

本页按当前 PCA 实现核对操作与统计定义；阶段验收结果以阶段文档为准，帮助登记不等于所有场景均已通过验证。

变量、预处理和主成分

选择多个数值变量建立基于 SVD 的 PCA；按需另选类别列为样本上色。样本的来源行号与类别必须使用相同有效行配对。缺失数据不默认插值或填补；无效数值、常量列和样本量不足应明确提示。

预处理模式约定
自动标准化 autoscale减训练均值，再除以训练样本标准差（ddof=1）。
均值中心化 center仅减训练均值，不缩放。
不缩放 none不中心化，也不缩放；此时主成分反映相对原点的二阶结构，不等同于中心化协方差 PCA。

主成分数可手动指定，且不能超过数值秩；留空时按累计解释方差目标选择最少主成分。特征值为预处理矩阵 Z′Z/(n−1) 的谱，解释方差比例为各特征值除以全部特征值之和。可参考 Scree Plot 和累计解释方差图。

交叉验证折数为 0 时关闭；启用时按输入行顺序连续分折、不随机打乱，每折仅用训练行估计中心、尺度和载荷，再重构整行留出样本。在各折预处理空间中汇总所有留出单元的残差平方，除以验证单元数得到重构 MSE；只报告每折均可计算的维数。每折训练数据至少两行且须可建模。该误差通常随维数增加而下降，仅作辅助显示，不自动选维、不证明最优维数，也不是遮蔽单元预测误差或未来样本预测能力的保证。

结果包括特征值、解释方差及累计贡献率、得分 Scores、载荷 Loadings、残差和重构值。新样本始终复用训练变量顺序、中心、缩放和载荷，不能在投影时重新估计预处理参数。

T²、Q 与贡献解释

Hotelling T² 衡量保留主成分空间内的偏离；Q Residual / SPE 是预处理空间中重构残差的平方和。监控分别显示 95% 和 99% 控制限及异常标记。

记 n 为训练有效样本数、k 为保留主成分数、c 为 0.95 或 0.99。T²=Σ(ta²/λa)，其中 t 为得分、λ 为保留特征值。T² 和 Q 的控制限均为单侧 95% / 99% 上限，直接使用 c 分位数，不将 α=1−c 再分为 α/2；比较采用双侧 α/2 约定的外部结果时，应先统一尾部概率。控制限针对单个观测，区分训练样本与独立新样本：

  • 训练 phase1：((n−1)²/n) × Betac(k/2, (n−k−1)/2)，要求 n>k+1。
  • 新样本 phase2：k(n+1)(n−1)/(n(n−k)) × Fc(k, n−k)，要求 n>k。

这些限假设独立、近似多元正态样本；PCA 子空间由训练样本估计，故按近似解释。不是均值检验或子组均值控制限。none 模式不满足中心化假设：虽仍可计算代数 T² 及贡献，但 T² 控制限与判异不可用，T² 异常标记为 pd.NA，不能当作正常。样本量不满足对应自由度时也标为未知；此时 Q 判异仍可用，若 Q 未超限，综合异常标记仍可能为未知。

综合异常采用 T² 超限或 Q 超限的 OR 规则，未校正同时检验或多个样本的多重比较。两个单项的 95% / 99% 上限不意味着联合误报率仍为 5% / 1%，也不提供全局覆盖率保证。

Q 限使用遗漏谱前两矩匹配的 scaled chi²（缩放卡方）近似：θ₁=Σλ遗漏，θ₂=Σλ遗漏²，g=θ₂/θ₁，h=θ₁²/θ₂，上限为 g × χ²c(h)。假设遗漏主成分近似独立正态，训练和投影共用训练谱，不能称为精确训练内分布。若遗漏方差为零，Q 限退化为零；判异只容忍矩阵运算舍入量级的残差，新样本偏离训练子空间仍可触发异常。

记 z 为预处理样本、P 为保留载荷、Λ 为保留特征值对角阵。变量 j 的 T² 贡献为 zj(PΛ⁻¹P′z)j，有正负且加和为 T²；Q 贡献为该变量预处理残差的平方，加和为 Q。负的 T² 贡献不是负的统计量。贡献表示模型中的偏离分配，不代表因果关系。

图形、状态探索和 A/B 选区

图形入口包括 Scree、累计解释方差、Score、Loading、Biplot、T²、Q 和 Contribution 图。二维图要求至少保留两个主成分，可选择其中任意两个不同主成分、类别颜色和图例、置信轮廓及异常标记。轮廓用训练得分样本协方差与 χ²(2) 分位数绘制，是二维正态假设下的近似覆盖轮廓，不是均值得分置信区间，也不能替代完整保留空间的 T² 或 Q 判异。训练得分不足三行或二维协方差奇异时不绘制。Biplot 的载荷箭头经过图中注明的视觉缩放，原始载荷请看载荷图或载荷表。

  1. 单击 Score 图样本，查看来源行号及变量贡献。
  2. 选择 A 组或 B 组，再使用矩形或椭圆选区；两组独立维护，显示各组样本数。组内样本不重复，A/B 两组允许重叠。
  3. 比较 A/B 组原始变量的样本数、均值、样本标准差（ddof=1）和均值差 A−B；单样本组标准差为空，空组均值和标准差为空。这是原变量描述统计，与选中样本在模型预处理空间中的 T² / Q 贡献不同，不构成两组差异显著性检验。
  4. 选区及点击关联当前结果对应的来源工作表，不能在切换工作表后按相同行号选中另一张表。投影样本关联投影来源，不冒用训练行号。

计算、模型与结果保存

PCADialog 在后台计算并提供取消；取消请求在当前计算返回后丢弃结果，保留上次有效模型，单次底层 SVD 不能强制中断。关闭窗口设置取消请求并关闭任务队列。

模型使用版本化 JSON 保存和加载，不使用 pickle 或 NPZ；包含变量顺序、训练预处理参数、完整特征谱、载荷、训练原值、来源标签和 CV 表。加载时校验版本、形状、有限值及模型与训练数据的一致性。复杂索引保存为带类型的显示标签，不重建任意 Python 对象；来源位置 source_row 仍保留。加载模型后可投影新样本，并继续使用训练时的预处理。加载的训练数据没有绑定当前工程表，须投影后才能定位新样本来源表。

选中结果表页后，可“当前表写入新工作表”或“导出当前表”为 Excel / CSV；得分、载荷、T²、Q、异常标记、选区和贡献表均沿用这一入口。“保存当前图形”和“保存贡献图”分别保存对应图形。“输出统计报告”发送当前已展示的非空结果表；原表保持不变，导出使用原精度数值。
