质量工具

帕累托图 Pareto Chart

质量 → 帕累托图。选择缺陷类别列。原始逐条缺陷记录不选频数列；已汇总数据另选非负整数频数列，重复类别会相加。分组列可空，非空时每组独立排序。同频按首次出现顺序。

默认累计超过 95% 后把剩余类别合并为末位“其他（合并）”；阈值空白关闭合并，100 显示全部。类别数量限制包含其他。零频数保留，每组总数必须为正；缺失输入拒绝。可输入中文标题、轴标签、显示 80% 线。

结果包含频数、百分比和累计百分比。每组图的柱、百分比标签、累计折线和右轴对应同一份结果。与 Minitab 不同：分组仅支持独立排序，不支持统一排序模式；不截断类别名称。

分析使用打开时的来源工作表快照。切换表不改变分析来源；关闭来源后拒绝输出。取消计算丢弃迟到结果。结果表可导出 CSV / Excel 或写入新工作表；打开图形后使用现有导航缩放、复位和保存图形。

运行图 Run Chart

质量 → 运行图。测量值按工作表原始行序，子组 ID 必须连续；不选 ID 时使用固定子组大小，要求完整子组。可选择子组均值或中位数。不绘制 SPC 控制限。

中位数相等归下侧；相邻相等归向下运行。围绕中位数的运行数期望为 1+2mn/N，方差为 2mn(2mn−N)/(N²(N−1))；上下运行数期望为 (2N−1)/3，方差为 (16N−29)/90。Z 为观测减期望除标准差，无连续性修正。四个 p 值是单侧正态近似：左尾聚集/趋势，右尾混合/振荡，默认 alpha=0.05。

与 Minitab 的适用门槛有差异：最少 3 点可绘图，但围绕中位数检验要求两侧各至少 10 点，上下检验要求至少 10 点且无相等观测。不满足时仍报告运行段数和期望，Z/p 显示 NA 并说明原因，不宣称随机。

因果图 / 鱼骨图

质量 → 因果图。输入问题（鱼头），树中默认人、机、料、法、测、环六类。名称框输入文字后用“新增类别”，或选父节点后“新增下级”；“修改选中”和“删除选中”编辑该节点及其子树。最多支持类别、原因、子原因三级。

导入时指定类别列、原因列和可选子原因列，空单元格代表无该级原因；空类别或无父原因的子原因拒绝导入。导入添加到现有结构；删除不需要的默认类别后再生成。修改后点击“分析 / 生成”重新生成，导出结构表或保存图形。布局自动增大画布，长文字换行；极密分支建议拆图。因果图组织分析假设，不证明因果关系。

多变异图 Multi-Vari

质量 → 多变异图。选择连续响应 Y 和 1–4 个不同分类因子。因子顺序决定图层：第一因子横轴、第二因子颜色连线、第三/四因子分面；调整选择顺序可探索交互。可关闭原始观测和图例，修改标题和轴标签。竖线为组合最小到最大值，均值点之间连接，表中同时给出 N、SD 和极差，N=1 的 SD 为 NA。

每因子至少两个水平，组合覆盖率须达到 Minitab 的 60% 门槛。缺失组合 N=0，图形断线；不填补。因子水平按首次出现（分类 dtype 按声明类别）排序。缺失/非有限输入拒绝。极不平衡（样本量比例超过 10）提示；超过 100 组合提示，超过 10000 组合拒绝以限制内存。超过 36 面板或横轴 100 水平时保留结果表、拒绝绘图并提示筛选。

与 Minitab 不同：这里使用组合均值连线和分面展示层级，不复刻其所有因子边际均值叠加样式。图形仅供探索，不作显著性结论；应另用 ANOVA 或回归检验。

属性一致性分析 Attribute Agreement Analysis

质量 → 属性一致性分析。输入长格式样本 Sample、评价员 Appraiser、评价 Response、可选试次 Trial 和标准 Standard。未填 Trial 时按每个样本/评价员原始行序推断。要求平衡完整交叉设计，同一试次集合、唯一记录键、同一样本标准一致；缺失、矛盾、单一全局类别拒绝。宽格式请先使用工具菜单堆叠成长格式。

名义类别不需要顺序；有序类别必须完整填写从低到高的类别顺序（逗号分隔）。所有 Kappa 为未加权绝对一致。三类以上有序评价另给出 Kendall W 和逐试次对标准的 tau-b；关联不等于分类正确。

完全一致率表以样本为单位：评价员内部要求所有试次相同；评价员之间要求所有人所有试次相同；评价员与标准要求该人所有试次都正确；全部与标准要求所有人所有试次都正确。单试次内部、单评价员之间标为 NA。正确评价比例另报告逐条正确率，不能与完全一致率混用。

完全一致率及逐试次正确率使用精确二项区间（内部等尾；全对/全错时按 Minitab 使用单侧 alpha）。跨相关重复评价的逐条正确率使用样本簇保守界：以全对样本概率的单侧下界作下限，以 1−全错样本概率的单侧下界作上限，两侧各 alpha/2；区间可能很宽，但不把重复评价当作独立样本。

内部至少两试次报告 Fleiss，恰好两试次另报 Cohen；之间至少两人报告 Fleiss，恰好两人各一次另报 Cohen。对标准按试次先算 Cohen/Fleiss，再分别平均。分类 Kappa 按该类别对其余类别二分类计算；分类不一致表显示完整实际/标准频数。

Kappa 渐近检验 H0:κ=0，H1:κ>0，SE0 是零假设标准误（不是估计量的非零假设 ASE）。仅 N≥30、期望频数足够且标准误非零时报告 Z 和右尾 p，否则保留点估计及原因。局部退化类别 Kappa=NA，不替换成 0 或 1。相关试次 Kappa 均值不报告 SE/Z/p。这比 Minitab 对标准均值使用独立方差的做法更保守。

Fleiss SE0 假定零假设下所有评分独立且共享类别概率 p；采用估计边际的 delta 方差 2(S2+S2²−2S3)/(N m(m−1)(1−S2)²)，S2=Σp²、S3=Σp³，以独立多项分配全枚举验证。该方差不直接照搬 Minitab 页面中的近似表达，不能据此声称 p 值逐位一致。

Kendall W 作并列校正，卡方近似 df=N−1，N≥10 才报告 p；tau-b 使用 SciPy 渐近右尾检验，N≥10 才报告 p。统计表可完整导出；无 Standard 时不生成与标准有关的表和图。
