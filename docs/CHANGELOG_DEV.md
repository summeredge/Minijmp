# 开发更新日志

## 未发布

### 2026-10-25

#### 工作表列公式

- 新增“计算”菜单的“计算器”：可选择目标列或输入新列名，按 C1、C2 等列位置编写表达式，结果写入工作表。
- 支持 `+`、`-`、`*`、`/`、`%`、`**`、括号、数值常量与 `ABS`、`SQRT`、`LOG`、`LOG10`、`EXP`、`ROUND`、`FLOOR`、`CEIL`、`TRUNC`；表达式经 AST 白名单校验，不执行任意 Python。
- 支持一次性计算与“关联公式”：关联公式记录源列依赖，源列编辑、粘贴、清除、行增删或程序内数据更新后自动重算；关闭自动计算后结果列标记待更新，可用“立即计算所有公式”刷新。
- 公式按依赖顺序重算，支持多级引用并拒绝直接或间接循环引用；目标列与源列均按稳定列名关联，重命名同步更新，列删除后明确标记公式失效，不静默引用错列。
- 工作表右键菜单新增“公式”子菜单：向列分配公式、编辑列公式、查看列公式、删除列公式、自动计算所有公式（可切换）、立即计算所有公式；关联结果列头显示 `[公式]`，待更新时追加 `*`。
- 关联结果列禁止手工编辑和粘贴，需先删除公式关联；解除关联后保留当前计算结果，转为普通数据列。一次性计算结果为普通数据列，不受源列变化影响。
- 列公式随工程文件保存目标列、表达式、源列映射、关联状态和自动计算设置；旧工程缺少公式信息时按普通工作表打开，普通 CSV、Excel 导出只写计算结果。
- 公式按当前工作表独立管理，不影响既有的应用函数、数值变换、筛选或统计分析读取。

修复（收尾验收）：

- 公式列粘贴保护改为按实际写入范围校验：单元格粘贴扩展到公式列或整行粘贴覆盖公式列时整次拒绝，不写入任何单元格，也不产生撤销记录。
- 工程文件保存并恢复手动计算模式下的待更新状态；重新打开后仍显示 `*`，执行“立即计算所有公式”后清除；自动计算模式仍按原机制重算，旧工程继续正常打开。
- 首行转列名时按列位置同步公式目标与来源；对公式源列执行所选列排序后触发原有公式更新流程，自动模式立即刷新结果，手动模式标记待更新，关联结果列不允许单独排序。
- 撤销/重做同时恢复数据与公式定义：创建、修改、解除关联公式后可正确回退和重做，普通数据编辑的撤销行为保持不变。
- 数值列名兼容：首行转列名产生数值列名后，公式的目标列及来源列按 DataFrame 实际列名类型保存和恢复，不再被转换为文本而导致重新打开后失配；`C1`、`C2` 位置引用语法及字符串列名工程保持不变。

验证：`tests/test_worksheet_formulas.py`（27 项）覆盖上述修复与原有场景，包含数值列名公式的工程保存、重新打开及重算；`tests/test_context_clipboard.py`、`tests/test_table_regressions.py`、`tests/test_worksheets.py`、`tests/test_worksheet_context_menu.py` 相关测试共 207 项通过。此前实际 Tk 计算器交互验证新列结果 25，源列改为 120 后自动更新为 50。

#### 改善前后控制图（阶段对比）

- I-MR、Xbar-R、Xbar-S 原控制图窗口新增“启用阶段对比（改善前/改善后）”，默认不勾选；未勾选时保留原有流程、绘图和报告。勾选后展开阶段划分方式、阶段列或时间列与分界点、控制限模式和显著性水平。Xbar 图沿用原窗口的子组大小或子组标识列。没有独立的“改善前后控制图”菜单项。
- 可按阶段列（按实际出现顺序识别两段）或时间列与分界点划分改善前、改善后；子组按阶段独立划分，不允许跨阶段。
- 支持“各阶段独立控制限”和“改善前固定基线”两种模式；后者只用改善前阶段的均值与组内波动，改善后沿用同一控制限，不重新估计。
- 输出两阶段样本数、均值、整体标准差、SPC 组内波动、均值变化率、标准差变化率、波动比及异常点数量和比例，并分别标注“整体”与“组内”口径；零均值、零方差显示“不适用”，不生成虚假变化率。
- 异常比例按阶段实际绘制点数计算：I-MR 为有效观测数，Xbar-R、Xbar-S 为子组数，表格分别显示“异常观测比例”和“异常子组比例”。同一观测或子组在主图与极差类图同时异常时，异常点数只计一次，规则记录数仍独立保留。
- 子组大小不等时，控制限汇总在变化单元格标注“逐子组变化”，并附逐子组 LCL/CL/UCL 明细；控制限恒定时只保留阶段汇总。明细、图形和异常判定共用同一份计算结果。
- 结果窗口按需显示“逐子组控制限”页：控制限固定时不出现空白页，逐子组变化时显示明细并可直接导出当前页。
- 自动执行 Ljung-Box 自相关检查；发现明显自相关时不再套用独立样本检验，Welch t 与 Levene 检验明确标记“显著性未评价”。样本不足以评价自相关时标记“独立性未充分评价”，同样不给出确定性显著性结论；常数列按“不适用”处理。
- 生成统一报告：数据摘要、各阶段 LCL/CL/UCL、异常点明细（阶段、图表、点号、来源行与标识、触发规则、窗口）、改善指标、统计检验、分析结论；明确统计显著不等同于因果改善，不把变化归因于 APC 或 PID 整定。
- 控制图沿用现有 PlotViewer，显示两阶段分界、不同颜色曲线、阶段控制限和异常点标记，图形可直接缩放、保存和导出。
- 普通 I、I-MR、Xbar-R、Xbar-S 控制图同步启用异常判定：I/Xbar 图按高级 SPC 的 Nelson 规则检查，MR/R/S 图只判定控制限越界；图中标记异常点，报告列出点号、来源标识、触发规则与说明。原菜单、控制限算法和高级 SPC 功能不变。

修复（收尾）：固定基线模式在改善前后子组大小不同时，Xbar-S 的 S 图中心线与控制限按改善后各子组的实际大小计算，不再沿用改善前子组大小。

修复（阶段对比收尾）：

- Xbar-R、Xbar-S 的每个子组改为读取自身阶段内的观测值。此前阶段局部下标被用于全局数组，改善后子组可能取到改善前数据；现按“阶段有效观测 + 阶段内子组下标”统一索引，含缺失观测和子组标识列时来源行仍对应原始工作表。
- 阶段图横轴按实际绘制点数定位：I-MR 为观测序号，Xbar 为子组序号，分界线落在改善前最后一个点之后，异常点与阶段名称随之对齐；横轴标签同步说明。
- 普通控制图异常点报告的来源标识（批次名、时间、中文阶段名等）改为按文本输出，不再因文本标签导致报告生成失败；统计量与控制限格式不变。
- Xbar 子组在统计计算前完成校验：单点子组直接提示对应子组标识并拒绝，Xbar-R 仍限制为 2 至 25 个观测；有效输入的计算结果不变。

验证：`tests/test_improvement_chart.py`（33 项）覆盖阶段顺序、时间分界校验、子组跨界拒绝、单点子组拒绝、指标计算、两种控制限模式、Xbar 阶段数据映射（1/2/3/4 与 101/102/103/104 的子组均值）、子组标识列与缺失行来源、不等子组控制限明细与绘图逐点一致、固定限时隐藏明细页而变动限时显示并导出、双面板同时异常不重复计数、异常比例分母（观测/子组）、按子组序号定位的阶段图、I 图 Nelson 一致性、极差图越限、强自相关与样本不足时不作显著性结论、零方差提示、原窗口勾选阶段对比及真实 Tk 结果窗口；与 `tests/test_g5_spc_reports.py`（74 项）合并 107 项通过。
