阶段控制图与改善对比

入口：质量 → 控制图 I-MR / Xbar-R / Xbar-S，在原窗口中勾选“启用阶段对比（改善前/改善后）”。未勾选时仍是原有控制图流程；勾选后展开阶段划分、控制限模式与显著性水平，点“确定”即可分析。没有单独的“改善前后控制图”菜单项。

Xbar-R、Xbar-S 的子组大小或子组标识列直接沿用原窗口设置；I-MR 使用单值与移动极差。分析结果在独立结果窗口中显示数据摘要、控制限、异常点、指标、检验与结论，可打开阶段控制图、写入新工作表或导出。

阶段划分

阶段列方式按数据实际出现顺序识别前后两个阶段，不按标签字母或字符串排序。例如标签依次为“改进后、改进前”时，第一段仍作为改善前。阶段标识只能形成两个连续段；出现交替重复或第三段时拒绝分析，并提示需要单独处理。

时间分界点方式要求时间列非递减且无缺失。分界前的时间归改善前，分界及之后归改善后；数值时间按数值比较，日期时间按日期时间解析。程序不会排序、补值或插值。两种方式都会在摘要中列出各阶段的样本数和起止行，便于核对来源。

观测值缺失的行会被排除并报告数量，其余行保持原始顺序；缺失行不会自动填补，也不会跨缺失重新划分阶段。

控制图与子组

I-MR 使用移动极差跨度 2。Xbar-R 和 Xbar-S 使用子组大小或子组标识列，子组按阶段分别划分。子组标识若同时出现在两个阶段、在阶段内不连续重复、含缺失，或阶段末子组不足两个观测，均拒绝计算。Xbar-R 子组大小上限为 25。子组不得跨越阶段边界。

主图（I 或 Xbar）使用高级 SPC 已有的 Nelson 1～8 规则；MR、R、S 图只判定是否超出控制限。规则区界沿用既有定义：区界点归内区，严格不等式才触发。异常点在图中用叉号标记，报告列出阶段、图表、点号、来源行、来源标识、统计值、实际控制限、触发规则、规则说明和窗口范围。来源标识为批次名、时间或阶段名等文本，按文本原样输出。

阶段图横轴按实际绘制点数定位：I-MR 为有效观测序号，Xbar-R、Xbar-S 为子组序号，分界线位于改善前最后一个点之后；点数与报告中的控制限、异常点位置一致。

两种控制限模式

各阶段独立控制限：分别估计改善前和改善后的中心线与组内波动。适合比较两阶段过程位置、波动和控制限本身的变化。

改善前固定基线：只用改善前阶段估计均值和过程标准差，改善后阶段沿用该中心和由它导出的控制限，不随改善后数据重新估计。适合判断改善后过程相对原基线是否发生偏移或出现新的异常。固定基线不改变改善前的原始控制限；I-MR 的 MR 图中心为 d2(2) 乘基线标准差。

子组大小不等时，Xbar 和极差类图的控制限随各组样本量变化。此时汇总表在相应单元格标注“逐子组变化”，并另附逐子组控制限明细（阶段、图表、点号、LCL/CL/UCL）；明细、图形和异常判定使用同一份计算结果。控制限恒定时只显示阶段汇总，不产生明细表。

指标口径

样本数按各阶段排除缺失后的有效行计数。均值、标准差（整体）使用阶段内全部有效观测，标准差为 ddof=1。SPC 组内波动由各阶段控制图实际中心线与控制限反算：I-MR 为 MR 中心 / d2(2)，Xbar-R 为 R 中心 / d2(n)，Xbar-S 为 S 中心 / c4(n)；固定基线模式的改善后组内波动沿用基线估计。

均值变化率 =（改善后均值 − 改善前均值）/ 改善前均值 × 100%。标准差变化率 =（改善后标准差 / 改善前标准差 − 1）× 100%，波动比 = 改善后 / 改善前。改善前均值为 0 或标准差为 0 时对应比率显示“不适用”，不会用虚假的改善率替代。

异常点数按“点”去重：同一观测或子组在主图和极差类图同时异常只计一次。分母为该阶段实际绘制点数，I-MR 用有效观测数，Xbar-R、Xbar-S 用子组数，因此表格分别显示“异常观测比例”和“异常子组比例”。异常规则记录数按规则命中记录计，可能大于异常点数。Nelson 重叠窗口、多个规则同时命中不视为彼此独立的异常事件。标准差下降只能说明波动缩小，不代表中心或规格符合性改善。

Xbar 子组在计算前校验：每个子组至少两个观测，Xbar-R 子组不超过 25 个观测。单点子组会直接提示相关子组标识，不进入统计计算。

适用性检查与检验

默认显著性水平 α = 0.05，可在窗口修改。程序先对两阶段分别做 Ljung-Box 自相关检查（滞后不超过 10，且不超过样本量的五分之一）。任一阶段存在明显自相关时，Welch t 与 Levene 检验均标记“显著性未评价”，并报告 p 值不可用，以避免把依赖样本误当独立样本。样本不足或阶段为常数列、导致自相关无法评价时，同样标记“独立性未充分评价”，不给出确定性的显著性结论。

无强自相关时，均值差异使用 Welch t 检验，波动差异使用 Levene（Brown-Forsythe，中心取中位数）检验；同时以 Spearman 秩相关检查阶段内趋势，显著趋势会作为解释限制提示。每阶段不足两个有效观测或常数列时，相应检验明确“不适用”。

统计显著差异不等同于因果改善，也不能直接归因于 APC、PID 整定或其他特定措施。结论应结合采样顺序、工况、测量系统和工程判断。

报告、图形与导出

窗口包含数据摘要、控制限与控制图结果、异常点明细、阶段指标对比、变化率与波动比、统计检验和分析结论。图形复用现有 PlotViewer，显示阶段分界线和阶段名称，控制限与表格来自同一份计算结果；可用查看器的缩放和保存功能。

“输出完整报告”写入来源工作表的文本结果，可复制、保存并导出其中的统计表。当前结果表可写入新工作表或导出 Excel / CSV。分析不修改原始工作表。

判断“描述性改善”与“统计显著改善”必须分别阅读：前者来自均值、标准差和异常比例的变化；后者还取决于适用性检查、样本量和显著性水平。
