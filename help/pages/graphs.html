通用绘图器

用途：用数据表当前选区的行、列绘图，并在同一窗口调整通用选项。它复用原有图表类型和绘图能力，不是 Minitab Graph Builder。

数据与参数：先在表格中选取要绘制的行、列；工具栏下方会显示本次绘图的当前输入摘要（行数、列数和列名）。选项面板含图形类型（默认折线图）、分组列与第二分组列、点标签列、点大小列、直方图组数（默认 20）、堆叠、子图、网格、图例、对数 X/Y、刻度标签、共享坐标轴、误差线列，以及线宽、标记、透明度和颜色设置；窗口工具栏另有 DPI（默认 80）、网格布局和三维图形开关。只有被选入绘图数据的列才能用于分组等字段。

两个重绘按钮：从选区重新绘图 会重新读取工作表当前选区，适合换行、换列或改选区后使用；应用设置并重绘 沿用窗口中已载入的数据，只应用新选项，不会取用之后修改的选区。

步骤：选取数据 → 选择 图形 → 通用绘图器 → 在选项面板改设置 → 点 从选区重新绘图 或 应用设置并重绘 → 用 保存 保存图像。参数区可通过右上角 隐藏参数区 / 显示参数区 收起或展开。

注意：图形类型和可用设置取决于所选数据；数据不适配时窗口会提示。选项面板可在窗口中显示或隐藏。Minitab 官方图形帮助（概念参考）

保存图形

用途：把当前 Plot Viewer 中的图形副本加入 图形菜单，供稍后重新打开或汇总导出。

步骤：先生成要保留的图，再选择 图形 → 保存图形。菜单会新增一项，以保存时的时分秒命名；点击该项会在新窗口打开图形。

注意：保存的是当前图形快照，不是数据或绘图参数；之后修改原图不会更新已存快照。

清除图形

用途：清空 保存图形 保存的图形列表及其动态菜单项。

步骤：选择 图形 → 清除图形 即可清空。

注意：此命令清理已存列表，不清除当前 Plot Viewer 正在显示的图。

PDF 报告

用途：把已存图形写入一个 PDF 文件。

步骤：先用 保存图形 保存所需图形，再选择 图形 → PDF 报告 并指定文件名和位置。每张已存图形占 PDF 一页。

注意：导出范围是当前已存图形列表；未存图、数据表和统计输出不会加入报告。

直方图与分布拟合

用途：查看一个数值列的分布，并可叠加一个指定分布的拟合曲线。

数据：选择一个数值 Data Column。

参数：Stats 可选 count（默认）、frequency、proportion、percent 或 density；Bins 和 Bin Width 默认 Auto，正数输入分别指定箱数或箱宽。Distribution 可选 Normal（默认）、Student's t、Gamma、Lognormal、Exponential、Weibull；Show Fit 默认关闭。X 轴可设标签、最小值和最大值；另有网格、图例及自动范围边距设置。

步骤与结果：选择列并设置选项，勾选 Show Fit 后点 Plot。直方图显示所选统计量；拟合结果同时输出到文本区，并以密度曲线叠加在图中。拟合曲线使用右侧次坐标轴，柱高与曲线高度未必可直接比较。

注意：此弹窗一次只拟合所选的一种分布，不提供多分布比较；需要比较拟合时使用 统计 → 分布拟合。Minijmp 的现有使用文档也将此入口描述为单分布绘图。Minitab 拟合分布线帮助（概念参考）

分组直方图

用途：按组比较一个数值变量的分布，或比较多个数值列的分布。

数据：长表输入使用 Data Col. 和可选 Group Col.；也可在列列表中选多个数值列。列列表选择会覆盖上方两项，并把各列堆叠后按原列名分组。

参数：箱数、箱宽及 Stats 与单列直方图相同。Multiple 可选 layer（默认）、dodge、stack、fill；Element 可选 bars（默认）、step、poly；另有 KDE、KDE Only、调色板、X 轴标签和范围、网格、图例及边距。

步骤与读图：选择一种数据形态并设置选项后点 Plot。颜色表示组别；Multiple 控制各组直方图的叠放方式。KDE 可叠加核密度估计，KDE Only 显示密度而不填充直方图柱。

注意：此图没有分布拟合选项；箱数和箱宽使用 Auto 时由绘图库决定。弹窗有 Margin 字段，但当前绘图函数不使用它；需用 X 轴 Min/Max 控制范围。Minitab 官方图形帮助（概念参考）

二维直方图

用途：用二维分箱查看两个变量的联合分布。

数据：选择 X Data Column 和 Y Data Column；Hue Data Column 可选，用于按类别区分数据。

参数：Bins 和 Bin Width 默认 Auto；X、Y 轴各可设标签、最小值和最大值。还可设置网格、图例、调色板及自动范围边距。弹窗没有 count/proportion 等统计量下拉项。

步骤与读图：选择 X/Y 列，可选 Hue 分组，点 Plot。图中的二维箱按箱内观测数着色，颜色差异反映观测集中程度。

注意：X、Y 应为可绘制的数值数据；箱数或箱宽保持 Auto 时由绘图库确定。弹窗虽有 Margin 字段，当前绘图函数不使用它；请用 X/Y Min/Max 控制范围。

延伸阅读：Minitab 图形类型概览（概念参考；图形选项以 Minijmp 为准）。

多变量箱线图

用途：比较一个或多个数值列的中位数、四分位范围和离散程度。

数据：可选一个 Data Col. 和可选 Group Col.；也可在列列表中选多个数值列。多列选择会覆盖上方选择，并把各列堆叠后按原列名分组。

参数：可设 X 轴标签、Y 轴标签及范围、水平参考线位置（逗号分隔）和参考线标签；Box Width 可选 Half（默认）、Full、1/4。Extended Features 包含 Swarm Dots、Swarm Only、Hide Fliers、Log Y；Whisker Length or Percentiles 默认 1.5，也可输入百分位二元组。另有 Native X Scale、网格和图例。

步骤与读图：选择单列加组别，或直接选择多列，设置参数后点 Plot。箱体表示四分位范围，中线表示中位数，须线按 whis 设置延伸；未隐藏时单独显示的点为离群值。Swarm Dots 可叠加观测点，Swarm Only 只显示点。

注意：Log Y 适用于正值数据；含零或负值时不适合对数坐标。Minitab 箱线图帮助（概念参考）

分组箱线图

用途：在同一数值列中按主组和子组比较分布。

数据：使用堆叠数据：Data Col. 为数值，Group Col. 可选并决定横轴分组，Subgrouping Col. (Hue) 可选并用颜色区分子组。

参数：可设 X 轴标签、Y 轴标签及范围、水平参考线和线标签、调色板、网格、图例、Box Width、Hide Fliers、Swarm Dots、Swarm Only、Log Y Scale、Native X Scale。Whisker Length or Percentiles 默认 1.5；Swarm 点大小默认 5，Separate 默认勾选。

步骤与读图：选数值列和分组列，可按需指定 Hue，设置选项后点 Plot。箱体、中位数、须线和离群点含义同上；Hue 用于在每个主组内区分子组。

注意：Log Y Scale 需要正值；Swarm Only 会隐藏箱体并保留观测点。Minitab 分组箱线图帮助（概念参考）

分组计数图

用途：统计类别值出现次数，并可按组并列或着色展示。

数据：使用 Data Col. 和可选 Group Col.；也可在列列表中选多个列。多列选择会覆盖上方输入，并把列名作为组别。

参数：Stats 可选 count（默认）、probability、proportion 或 percent；可设 X 轴标签、Y 轴标签和范围、水平参考线及线标签、调色板、网格和图例。

步骤与读图：选择类别列和可选分组，设置纵轴统计量后点 Plot。柱形高度按 Stats 的选项表示计数或归一化比例。

注意：每根柱对应一个类别；类别过多时标签会拥挤。Minitab 官方图形帮助（概念参考）

线条图

用途：按 X 值展示 Y 值变化；可按组绘制多条线，或比较多个 Y 列。

数据：长表使用 Y Data Col.、必选 X Data Col. 和可选 Group Col.；宽表可在 Y Data in its own column 列表中选多个 Y 列，列表选择覆盖上方 Y/Group 输入，X Data Col. 仍需指定。

参数：X、Y 轴标签，Y 轴 Min/Max，水平参考线及标签，网格、图例、边距和调色板。X 轴 Min/Max 虽显示在弹窗中，但当前源码未将其传给绘图函数；分组列或宽表原列名用来区分线条。

步骤与读图：选择 Y、X 和可选组别，或选择多列 Y 并指定共同 X，设置参数后点 Plot。线条显示 Y 随 X 的变化；重复 X 值会按绘图库的 lineplot 默认规则汇总。

注意：确认 X 列的顺序和取值含义；连线会影响趋势观感。Margin 字段目前不参与坐标范围计算；X 轴范围自动，Y 轴可用 Min/Max 设置。Minitab 官方图形帮助（概念参考）

时间序列图

用途：绘制连续采样数据的原始趋势，保留重复时间戳和缺失值，不聚合、插值或平滑。

步骤：选择 图形 → 时间序列图。选择时间列，或勾选样本序号；在数值列列表中按 Ctrl/Shift 多选 Y 变量。选择单 Y 轴、双 Y 轴或多 Y 轴，在右侧表格选中变量后，用下方下拉框指定所属 Y 轴，点“绘图”。

轴与标题：单轴模式全部归 Y1；切到双轴时 Y3 及以上归 Y2；多轴模式保留有效归属。切换模式不会取消变量选择。Y1 在左侧，Y2 及后续轴在右侧依次外移，只创建实际使用的轴。可设置图形、X 轴和各 Y 轴标题；Y 轴标题留空时使用变量名。

数据与操作：时间列按升序稳定排序，重复时间保留原有相对顺序；样本序号从 1 开始，保持原行顺序。无效或缺失时间须先修正；Y 缺失值显示为断线。窗口内可用工具栏平移、框选缩放、返回原视图及保存图像。重新绘图会替换上次预览。

散点图

用途：以点展示 X 与 Y 的观测关系，并可按组或多个 Y 列区分数据。

数据：长表使用 Y Data Col.、必选 X Data Col. 和可选 Group Col.；宽表可在 Y Data in its own column 列表中选多个 Y 列，列表选择覆盖上方 Y/Group 输入，X Data Col. 仍需指定。

参数：X、Y 轴标签，Y 轴 Min/Max，水平参考线及标签，网格、图例、边距和调色板。X 轴 Min/Max 虽显示在弹窗中，但当前源码未将其传给绘图函数。

步骤与读图：选列并设置参数后点 Plot。每个点表示一条观测；同一位置重叠时，点数可能不易直接辨认。

注意：此入口使用散点图绘制点，不提供拟合线或相关分析。Margin 字段目前不参与坐标范围计算；X 轴范围自动，Y 轴可用 Min/Max 设置。Minitab 散点图帮助（概念参考）

概率图

用途：根据指定分布参数查看理论分布、分位数或某个 X 处的概率。

参数：分布默认 Normal；可选 Normal（Mean、Standard deviation）、Chi Square（Degrees of freedom）、F（Numerator/Denominator degrees of freedom）、LogNormal（Scale）、t（Degrees of freedom）、Binomial（Number of trials、Event probability）或 Poisson（Mean）。参数输入框默认空白，需按所选分布填写。可输入概率 P 或 X；X 优先于 P。Show Plot 默认勾选。

结果：文本区输出理论均值、方差、标准差、偏度和峰度。输入 P（需满足 0<P<1）时输出尾部分位数和等尾界限；输入 X 时输出该点的密度或概率质量及左右尾概率。连续分布绘制密度曲线；Binomial 和 Poisson 绘制概率柱。

注意：图中用参考线或标记指出尾部位置，不会填充阴影区域。Binomial 的 Number of trials 及离散分布的 X 按整数处理。LogNormal 弹窗字段名为 Scale；当前源码将其作为 SciPy 对数正态分布的首个位置参数传入，参数化需按此实现理解。

延伸阅读：Minitab 图形类型概览（仅作分布图的概念参考）。

概率图对比

用途：把两组指定参数的理论分布叠加显示，便于目视比较曲线或概率质量。

参数：Distribution 1 和 Distribution 2 默认均为 Normal；各自支持 概率图 中列出的七种分布及对应参数，参数框默认空白。此弹窗没有 P、X 或 Show Plot 选项。

步骤与结果：分别选择分布并填写参数后点 Plot。文本区分别输出两组分布的参数和理论统计量；连续分布画密度曲线，Binomial/Poisson 画概率柱。第一组为蓝色，第二组为绿色。

注意：虽然菜单名称为“概率图对比”，此实现是两种分布的理论曲线叠加，不是概率图，也不执行拟合优度或两分布差异检验。

延伸阅读：Minitab 图形类型概览（仅作分布图的概念参考）。

条形图

从“图形”菜单分别打开所需图形，选择数值列后点“绘图”。可重复调整，使用原有查看器的保存按钮输出图片。原工作表不会被修改。

条形图：每一行的数值直接决定条形高度，可选水平条形；不是类别频数统计。饼图选择一列非负数值，合计须大于零。条形、饼图和区域图可选择标签列，默认使用行索引；重复标签仍按独立行绘制，不自动求和或取平均。区域图按工作表行顺序叠加非堆叠区域。

点图：每个所选列为一组，显示全部有限观测值及箱线摘要，水平方向轻微抖动以区分重叠点；不要求 X-Y 配对。原“散点图”仍使用 X-Y 成对数据。矩阵图至少选择两列，每列至少有两个不同数值，对角线为直方图，非对角线为所有变量对的散点关系。

等值线图、三维散点图、三维曲面图：分别指定不同的 X、Y、Z 列。等值线和曲面沿用三次插值，至少三个非共线的完整有限点；拒绝重复 X-Y 坐标及插值失败，不会静默聚合。凸包外为空白，不外推。三维散点不要求点形成曲面。

缺失数据：数值列必须能够转换为数字。空值和无穷值不参与绘图；除点图按列保留有限值外，其他图形按所选数值列的完整行绘制。请先清洗数值列中的非数值文本；无有效数据会提示错误。

饼图

图形 → 饼图。选择一列非负数值，可指定标签列；每行数值决定扇区比例，合计须大于零。

区域图

图形 → 区域图。选择一列或多列数值，按工作表行顺序绘制非堆叠区域，可指定标签列。

点图

图形 → 点图。每个数值列独立成组，绘制全部有限观测值和箱线摘要；横向抖动不表示第二个变量。

矩阵图

图形 → 矩阵图。选择至少两列，各列至少两个不同数值；显示完整变量对关系和对角线直方图。

等值线图

图形 → 等值线图。指定 X、Y、Z 数值列，至少三个非共线完整点；重复 X-Y 坐标需自行处理，凸包外不外推。

三维散点图

图形 → 三维散点图。指定不同的 X、Y、Z 数值列，每行对应一个三维观测点。

三维曲面图

图形 → 三维曲面图。指定 X、Y、Z 列，沿用三次插值；点不足、共线、重复坐标或插值失败时提示错误。

气泡图

入口：图形 → 气泡图。

X、Y、面积三列完整配对，删除缺失及无穷值；可选分类缺失行排除。面积必须非负且至少一个正值，零值不可见；面积按原值/最大值×500 pt²缩放，图内显示比例；分类按颜色显示。

不修改工作表。非数值内容报错，缺失和无穷值排除，不填补或插值。无效输入保留已有图形。图形可设置标题、轴标签、网格和水平参考值，并通过现有查看器保存 PNG、SVG、PDF；茎叶图使用文本窗口。分类按照首次出现顺序显示。

经验累积分布函数图

入口：图形 → 经验累积分布函数图。

逐列及逐分类使用有限观测，F(t)=观测值不大于 t 的个数/样本数。阶梯形式，重复值累计跳跃，纵轴固定为 0～1；不拟合、不插值。

不修改工作表。非数值内容报错，缺失和无穷值排除，不填补或插值。无效输入保留已有图形。图形可设置标题、轴标签、网格和水平参考值，并通过现有查看器保存 PNG、SVG、PDF；茎叶图使用文本窗口。分类按照首次出现顺序显示。

单值图

入口：图形 → 单值图。

各数值列及可选分类分别显示全部原始有限观测，水平抖动不改变纵坐标。不聚合、不默认显示均值，与 X-Y 散点图及旧点图区分。

不修改工作表。非数值内容报错，缺失和无穷值排除，不填补或插值。无效输入保留已有图形。图形可设置标题、轴标签、网格和水平参考值，并通过现有查看器保存 PNG、SVG、PDF；茎叶图使用文本窗口。分类按照首次出现顺序显示。

区间图

入口：图形 → 区间图。

各列及分类按原始有限观测计算均值与 Student-t 双侧置信区间：均值 ± t((1+C)/2,n−1)×s/√n，s 为无偏样本标准差。默认 C=95%，独立同分布、正态总体假设下为精确区间。每组至少两个观测；常数列区间宽度为零。此入口不同于单因子方差分析的区间定义。

茎叶图

入口：图形 → 茎叶图。

选择一列有限观测，按数值排序，重复值保留。叶单位为 10^指数，自动按最大绝对值选择，支持 -308～308 的整数指数。直接读取原始十进制值，不先转二进制浮点数；朝零截断，不四舍五入；误差小于一个叶单位，负零茎保留符号。输出说明单位、N 和读法；细分范围超过 1000 个叶单位时提示增大单位。复用文本统计结果窗口，可复制或保存文本；不生成 PNG 图形。
