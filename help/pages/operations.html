项目文件

用途：新建工作表，或保存并继续编辑 Minijmp 项目。

  • 新建项目：创建空表，并可指定行列数。
  • 打开项目 / 保存 / 另存为：打开或保存 Minijmp 的 pickle 项目文件。它保存当前工作表状态，与 CSV、Excel 数据交换文件不同。

步骤：使用 文件菜单打开项目，完成编辑后选“保存”；首次保存或另存为时选定文件路径。

CSV 和 Excel 导入后成为当前工作表；再次打开项目文件不会把它们自动合并。

CSV 导入

用途：将 CSV、TSV 或文本表格读入当前工作表。

数据要求：记录应有一致的列数。默认导入会识别 UTF 编码标记、尝试 UTF-8、GB18030 或 CP1252，并检查逗号、制表符、分号和竖线分隔。

操作：选 文件 → 导入 CSV。软件会尝试判断分隔符和首行表头；判断不确定时会显示预览，让你确认编码、分隔符及“首行为表头”。

注意：默认导入会推断纯数字列。若数字看似编号、需要保留前导零或文本格式，请使用 高级导入 并选择按字符串导入数字。

高级文本导入

用途：在导入前手动调整 CSV / 文本解析方式并预览结果。

可调参数：分隔符、表头行位置、小数符号、注释符、跳过前置空格、跳过行、忽略空白行、数字按字符串处理、解析日期、日期格式、编码、读取行数和自定义列名。

操作：选 文件 → 高级导入，选择参数后点 Update preview；检查文本及表格预览，再点 Import。

日期格式留空时由 pandas 推断；若预览列数或日期不正确，先检查分隔符、编码和表头行。

导入 PI 数据

通过 文件 → 导入 PI 数据 打开窗口。选择可运行的 PIReader.exe 和现有 config.txt；PIReader 所需的 PI SDK 必须安装在本机，且能够访问配置的服务器。Minijmp 不包含 PI SDK 或 PIReader 二进制文件，也不需要启动 Dash 服务。

默认查找 Minijmp 项目目录内的 PIReader.exe 和 config.txt，也可通过 PI_READER_EXE、PI_CONFIG 环境变量或窗口浏览按钮指定位置。不会读取、保存或记录配置文件内容；不要将带凭据的 config.txt 加入版本控制。

每行输入一个 Tag（最多 20 个，忽略大小写去重），或输入 Tag Mask 搜索、勾选后添加。时间支持绝对时间及现有 PI 表达式（如 *、*-1h、*-1d）；采样间隔支持 1m、5m、10m、30m、1h。预计超过一百万个数据点或无法估算时会要求确认，不截断查询数据。搜索结果如被 PIReader 限制会明确提示缩小 Mask。

成功后以 Timestamp 列及原始 Tag 列替换当前工作表；若 Tag 名为 Timestamp，保留 Tag 原名，时间列使用 Timestamp (time 1)，编号递增避开已有 Tag 名，可继续统计、绘图和保存。未保存的原工作表会被替换；需要保留时请先保存。空结果、错误、超时和取消不改变原工作表。

查询在后台线程运行，最长等待 300 秒。取消会立即关闭窗口并丢弃迟到结果；已经启动的 PIReader 仍可能运行到完成或超时。窗口不持久化路径、Tag 或凭据。

查询状态和完整错误信息显示在固定高度的只读文本框中，可滚动查看和复制。

读取的是指定采样间隔的插值历史数据。

Excel 导入

用途：从 Excel 工作簿读取一个工作表。

支持格式：.xls 和 .xlsx。选择文件后，从工作簿中的工作表名称里选取要载入的表。

注意：此入口一次载入所选工作表；不会自动合并同一工作簿的其他工作表。

CSV 导出

用途：把当前工作表保存为 CSV，供其他程序读取。

操作：选 文件 → 导出 CSV，指定文件名和位置。

当前主菜单提供 CSV 导出，没有 Excel 导出命令。若需 Excel 文件，请先导出 CSV，再用目标程序打开并另存为工作簿。

编辑表格

编辑菜单提供撤销和重做、复制整表或选中单元格、粘贴、清除选中值、删除所选行并上移、查找与替换，以及首选项。

粘贴时可选择是否带入列标题。查找/替换 按单元格内容查找；替换前请确认当前选择和筛选状态。

视图

视图菜单可以放大或缩小表格显示、切换列标题换行，以及选择深色或浅色主题。这些操作只改变查看方式。

数据菜单

数据菜单用于改单列或整理数据：创建分类列、应用函数、重采样或变换、统计值计数、字符串操作、日期时间转换、筛选行、拆分列、堆叠列、排序全部或选中列，以及把首行转成列标题。

提示：拆分列与堆叠列可把宽表和长表互相整理；筛选后先检查过滤状态，再执行会改写数据的操作。

工具菜单

工具菜单提供列名与数值转换、数据清理、重复值查找、表格文本和信息查看、值变换、分组汇总、交叉表、合并或拼接表、透视、融化和时间序列重采样。

选择数据时：分组汇总和交叉表需要类别列；均值、合计等汇总统计需要合适的数值列。合并前确认键列和两表的列名。

表格和列标题右键菜单

在表格或列标题上右键可打开与当前位置相关的操作，包括增删行列、填充数据、排序、改列名或类型、表格信息和部分列操作。可用命令取决于点击的是单元格还是列标题。
