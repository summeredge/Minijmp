项目文件

工程保存已完成的文本报告、结构化统计表和 Matplotlib 图形快照。重新打开后，切换至来源工作表，再从“视图 → 查看统计结果”查看或导出报告。图形快照从“图形”菜单打开，可保存图片，也可随图形历史导出 PDF。快照记录原分析，修改数据后可另行分析。

用途：新建工作表，或保存并继续编辑 Minijmp 项目。

  • 新建项目：创建空表，并可指定行列数。
  • 打开项目 / 保存 / 另存为：打开或保存 Minijmp 的 .dexpl 工程。工程用版本化 JSON 保存元数据、用 Parquet 保存工作表数据；CSV 和 Excel 用于数据导入，不保存完整工程状态。

步骤：使用 文件菜单打开项目，完成编辑后选“保存”；首次保存或另存为时选定文件路径。

随包提供的 .dexpl 示例可在“文件 → 打开项目”窗口中选择。

当前版本不打开旧版 pickle 工程或 .pickle 单表文件。需要迁移历史工程时，请联系公司 IT 制定隔离环境迁移方案；不要在普通环境打开旧版文件。

CSV 导入

用途：将 CSV、TSV 或文本表格读入当前工作表。

数据要求：记录应有一致的列数。默认导入会识别 UTF 编码标记、尝试 UTF-8、GB18030 或 CP1252，并检查逗号、制表符、分号和竖线分隔。

操作：选 文件 → 导入 CSV。软件会尝试判断分隔符和首行表头；判断不确定时会显示预览，让你确认编码、分隔符及“首行为表头”。

注意：默认导入会推断纯数字列。若数字看似编号、需要保留前导零或文本格式，请使用 高级导入 并选择按字符串导入数字。

高级文本导入

用途：在导入前手动调整 CSV / 文本解析方式并预览结果。

可调参数：分隔符、表头行位置、小数符号、注释符、跳过前置空格、跳过行、忽略空白行、数字按字符串处理、解析日期、日期格式、编码、读取行数和自定义列名。

操作：选 文件 → 高级导入，选择参数后点 Update preview；检查文本及表格预览，再点 Import。

日期格式留空时由 pandas 推断；若预览列数或日期不正确，先检查分隔符、编码和表头行。

导入 PI 数据

通过 文件 → 导入 PI 数据 打开窗口。选择可运行的 PIReader.exe 和现有 config.txt；PIReader 所需的 PI SDK 必须安装在本机，且能够访问配置的服务器。Minijmp 不包含 PI SDK，也不需要启动 Dash 服务。

Windows 发布包在 MiniJMP.exe 同级附带 PIReader 文件夹，内含 PIReader.exe 与 config.txt；目标机可能仍需安装 PIPC/PI SDK 运行时。程序固定运行应用根目录下 PIReader 文件夹内的 PIReader.exe，不能通过界面、注册表或环境变量改为其他程序；config.txt 可通过 PI_CONFIG 环境变量或窗口浏览按钮另行指定。窗口只保存 config.txt 路径，不会读取、保存或记录配置文件内容。

每行输入一个 Tag（最多 20 个，忽略大小写去重），或输入 Tag Mask 搜索、勾选后添加。时间支持绝对时间及现有 PI 表达式（如 *、*-1h、*-1d）；采样间隔支持 1m、5m、10m、30m、1h。预计超过一百万个数据点或无法估算时会要求确认，不截断查询数据。搜索结果如被 PIReader 限制会明确提示缩小 Mask。

成功后以 Timestamp 列及原始 Tag 列替换当前工作表；若 Tag 名为 Timestamp，保留 Tag 原名，时间列使用 Timestamp (time 1)，编号递增避开已有 Tag 名，可继续统计、绘图和保存。未保存的原工作表会被替换；需要保留时请先保存。空结果、错误、超时和取消不改变原工作表。

查询在后台线程运行，最长等待 300 秒。取消会立即关闭窗口并丢弃迟到结果；已经启动的 PIReader 仍可能运行到完成或超时。窗口不持久化路径、Tag 或凭据。

查询状态和完整错误信息显示在固定高度的只读文本框中，可滚动查看和复制。

读取的是指定采样间隔的插值历史数据。

Excel 导入

用途：从 Excel 工作簿导入工作表。

支持格式：.xls 和 .xlsx。导入后，工作簿中的每个工作表都会成为一个 MiniJMP 工作表。

HDF5 文件暂不可导入；请先在来源程序中导出为 CSV 或 Excel。

CSV 导出

用途：把当前工作表保存为 CSV，供其他程序读取。

操作：选 文件 → 导出 CSV，指定文件名和位置。

当前主菜单提供 CSV 导出，没有 Excel 导出命令。若需 Excel 文件，请先导出 CSV，再用目标程序打开并另存为工作簿。

编辑表格

编辑菜单提供撤销和重做、复制整表或选中单元格、粘贴、清除选中值、删除所选行并上移、查找与替换，以及首选项。

粘贴时可选择是否带入列标题。查找/替换 按单元格内容查找；替换前请确认当前选择和筛选状态。

视图

视图菜单可以放大或缩小表格显示、切换列标题换行，以及选择深色或浅色主题。这些操作只改变查看方式。

数据菜单

数据菜单可创建分类列、应用函数、重采样或变换、统计值计数、处理字符串和日期时间、筛选行、子集化工作表、拆分或堆叠列、排序，以及把首行转成列标题。

提示：拆分列与堆叠列可把宽表和长表互相整理；筛选后先检查过滤状态，再执行会改写数据的操作。

子集化工作表

选择「数据 → 子集化工作表」。按条件可设置列比较、闭区间、为空或非空，多个条件统一使用且（AND）或或（OR）。文本区分大小写，使用精确匹配或按文本顺序比较。缺失值使用为空或非空判断，普通比较跳过缺失值。

按行号可输入 1-10,15,20-30。两种模式都在当前可见行内操作，行号按显示顺序从 1 开始。选择包含或排除，点击「预览行数」检查匹配行数和结果行数。

确认后切换到独立的新工作表，保留全部列、数据类型和原行顺序。零行结果会保留列结构。原表和筛选状态保持原样，结果表使用普通数据工作表格式。

按类别拆分工作表

选择「数据 → 按类别拆分工作表」，选中一个或多个分类列。每种取值或取值组合生成一张工作表，缺失值也参与分组。若已筛选，只拆分当前可见行。

点击「预览」查看可见总行数、预计生成的表数及各表名称和行数。组合名称用下划线连接，缺失值显示为「缺失」，表名沿用现有的清理和去重规则。

点击「确定」创建并切换到第一张结果表。各表按分组首次出现的顺序排列，保留全部列、数据类型及组内行顺序。原表与筛选状态保持原样，结果表为普通数据工作表。拆分后的工程最多包含 256 张工作表。

逆堆叠、随机数据与概率分布

使用「数据 → 逆堆叠列」，选择数据和分组列。按每组首次出现的顺序建列，保留组内行序和原有缺失值，较短列以缺失值补齐。分组列的缺失值构成一组，同名输出列自动加后缀。结果写入新工作表。

使用「工具 → 从列随机抽样」选择一列或多列。各列按同一批行抽样，保留相同行中的对应关系及缺失值。无放回抽样的样本量不能超过可见行数。「生成随机数据」支持正态、均匀、二项和泊松分布。两项工具都可填写非负整数种子，以同样的输入重复生成结果。

使用「工具 → 概率分布」选择正态、二项或泊松。PDF 表示连续密度，PMF 表示整数点的概率质量，CDF 计算 P(X≤x)。逆 CDF 使用 SciPy 分位数定义，离散分布对 0<p<1 取达到指定概率的最小整数。端点沿用 SciPy，例如正态返回 ±∞，二项和泊松在 p=0 返回 −1，泊松在 p=1 返回 +∞。缺失输入产生缺失结果。

概率输入可选常数或现有列。新工作表包含所命名的结果列。写入当前表时必须使用新列名；常数结果填满该列，列输入逐行对应。筛选生效时可将可见行结果写入新工作表。

合并项目工作表

在“工作表 → 合并项目工作表”分别选择左表和右表。按键匹配时，两侧选中的键按各自列顺序依次配对，列名可以不同。可选内、左、右和全外连接。组合键任一分量缺失时不匹配，重复键保留所有匹配组合。

按行并列使用源表现有行顺序，较短的一侧补缺失。分别选择两侧的输出列。输出依左表、右表顺序排列，发生重名时对后出现的列附加侧别，必要时再加序号。

预览显示源表行数、结果行数和匹配情况，最多展示前 20 行。确认后创建新表，取消时不创建。结果包含源数据值，源表上的列公式及 DOE 设计属性留在源表中。

工具菜单

工具菜单提供列名与数值转换、数据清理、重复值查找、表格文本和信息查看、值变换、分组汇总、交叉表、合并或拼接表、透视、融化和时间序列重采样。

选择数据时：分组汇总和交叉表需要类别列；均值、合计等汇总统计需要合适的数值列。合并前确认键列和两表的列名。

单元格、行列标题和工作表标签右键菜单

单元格：复制所选、粘贴、撤销或清除所选。右键点在现有选择内会保留选择；点在外面会改以该单元格为目标。粘贴按制表符分隔并覆盖现有单元格，不插入行列；尺寸或边界不匹配时不会写入。只读表格和筛选状态会阻止修改。

列标题：保留排序、增删、重命名和格式操作，并可复制或粘贴整列及多列；选中列标题后 Ctrl+C 复制整列、Ctrl+V 粘贴整列。最后一列右侧的空白标题栏右键可添加一列，或输入列数一次添加多列。行标题：保留索引和行操作；“复制行”会在表内复制，“复制整行”会复制到系统剪贴板。

工作表标签：右键标签可新增、复制、重命名、删除或导出工作表。操作针对命中的标签；空白标签栏不弹出菜单，删除前会确认。

分析导航与历史

从“视图 → 分析导航”显示或隐藏面板。结果按来源工作表归类。切换工作表时，当前表所在组展开。打开分析条目可查看历史信息和文本或统计表；展开带有报告及图形的分析可单独打开图形快照。

历史显示时间、可取得的输入列和参数。删除条目前会确认，确认后该条目的报告和图形从工程历史移除。工程保存后恢复历史、面板显隐和选中分析。来源删除后的记录显示为“已删除”。
