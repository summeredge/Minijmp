Minijmp 离线帮助

在左侧目录浏览，或搜索功能名称和正文。帮助页可离线阅读；“延伸阅读”链接只有在点击时才会联网。

开始使用

  1. 从 CSV 导入 或 Excel 导入载入数据。
  2. 从“统计”“质量”或“图形”菜单选择分析。
  3. 在参数窗口按 F1 或点“帮助”，查看当前分析的说明。

阅读结果

帮助按当前 Minijmp 的实现说明输入列、可用参数和输出。统计结论应结合数据条件、样本设计和实际背景判断；p 值或能力指标本身不替代专业判断。

数据操作

项目文件与数据文件用途不同：项目文件保存工作表状态；CSV 和 Excel 用于导入或交换表格数据。详见 文件操作。
