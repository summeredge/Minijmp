PIReader 与 PI SDK 说明

PIReader/PIReader.exe 是 MiniJMP 项目自研程序，按项目 GPL-3.0-or-later 许可；Windows 运行包中的程序位于 PIReader/PIReader.exe。代码签名不表示 Windows 或其他计算机信任签名者。

公开 Windows 包复用已验证的自研 PIReader.exe，版本和摘要见 BUILD-INFO.txt，不提供 OSIsoft.PISDK.dll、OSIsoft.PISDKCommon.dll 和 OSIsoft.PITimeServer.dll。企业内部构建仍随附三个 PI SDK 相关组件，用于支持 PI 数据访问。PI 数据导入功能须在已取得相应授权、安装并正确配置 PI SDK/PIPC 运行环境，且具有 PI Server 访问权限的企业办公终端上使用。随包组件不构成完整的 PI System 运行环境，也不代表授予额外的软件使用或再分发许可。 三个 DLL 保持专有第三方身份，再分发授权待企业确认；公开 Git 与源码 ZIP 不含 SDK DLL，不自动安装或注册组件。

PIReader 依赖 .NET Framework 4.8，并需要可访问的 PI Server、配置和标签文件。本次未验证企业 PI 连接；不会自动安装或注册 PI SDK/PIPC 系统组件。

默认配置文件为 <MiniJMP程序根目录>/PIReader/config.txt；公开包仅含空白配置和标签模板。已保存路径、手动选择和 PI_CONFIG 覆盖保持原优先级，不覆盖用户配置。源码包不含本机真实配置、凭据或 SDK DLL。不随包分发 DLL 不代表全部软件许可要求已确认。
