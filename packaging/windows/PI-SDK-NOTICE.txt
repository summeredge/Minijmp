PIReader 与 PI SDK 说明

PIReader/PIReader.exe 是 MiniJMP 项目自研程序，按项目 GPL-3.0-or-later 许可；当前 Windows 运行包将本次源码编译的程序放在 PIReader/PIReader.exe。代码签名不表示 Windows 或其他计算机信任签名者。

MiniJMP V1.1 Windows 发布包随附三个 PI SDK 相关组件，用于支持 PI 数据访问。PI 数据导入功能须在已取得相应授权、安装并正确配置 PI SDK/PIPC 运行环境，且具有 PI Server 访问权限的企业办公终端上使用。随包组件不构成完整的 PI System 运行环境，也不代表授予额外的软件使用或再分发许可。 三个 DLL 保持专有第三方身份，再分发授权待企业确认；公开 Git 与源码 ZIP 不含 SDK DLL，不自动安装或注册组件。

PIReader 依赖 .NET Framework 4.8，并需要可访问的 PI Server、配置和标签文件。本次未验证企业 PI 连接；不会自动安装或注册 PI SDK/PIPC 系统组件。
