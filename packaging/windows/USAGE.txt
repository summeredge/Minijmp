MiniJMP v1.0.0 (V1.0) — Windows x64

运行
1. 将整个 ZIP 内完整的 MiniJMP 运行文件夹解压到可写位置。
2. 双击 MiniJMP.exe。不要单独移动 exe；同目录的 _internal 文件夹包含运行时。
3. 无需安装 Python、无需管理员权限，也无需运行安装程序。

数据与工作表
- 可导入 CSV、TSV、TXT、XLS、XLSX；Excel 工作簿中的每个工作表会导入为一个 MiniJMP 工作表。HDF5 暂不可导入，请先导出为 CSV 或 Excel。
- 可导出 CSV 和 XLSX；多工作表工程保存为 .dexpl。.dexpl 使用版本化 JSON 元数据和 Parquet 表格数据，不使用 pickle。
- 随包提供的 .dexpl 示例工程可从“文件 → 打开项目”窗口选择。
- 当前版本拒绝打开旧版 pickle 工程及 .pickle 单表文件。需要迁移历史工程时，请联系公司 IT 制定隔离环境迁移方案；不要在普通环境打开旧版文件。

配置与日志
- 表格默认配置及错误日志写入 %LOCALAPPDATA%\MiniJMP\。
- 应用偏好设置保存在当前 Windows 用户目录下的 .dataexplore 文件夹。
- 工作文件请保存到您有权限访问的位置。

PI 数据
- 包内 PIReader 文件夹包含本项目自研且已签名的 PIReader.exe 和干净配置模板；不包含 OSIsoft PI SDK DLL。程序路径为 PIReader/PIReader.exe。
- OSIsoft DLL 仍为专有第三方组件；其许可和再分发授权不因打包或代码签名而改变。使用 PI 还需要 .NET Framework 4.8、匹配的 PI SDK/PIPC 与 PI Server 访问权限；本次未验证企业 PI 连接。
