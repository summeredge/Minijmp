## 修复

- 表格写入统一进行 dtype/精度校验并先暂存列副本，再提交；单元格编辑、清除、粘贴、上移、向下填充与查找替换在失败时不产生部分修改，保护关联公式结果列。清除整型值时避免整列浮点化导致大整数舍入。
- CSV/Excel 数值推断保留大于 `2^53` 的整数、高精度小数和带前导零编号；`.xlsx` 从原始 XML 恢复被读取器舍入的 numeric token，多工作表导入保持原样。PI Reader 原有 `Decimal`/object 精度防护未动；PI 频率单位映射避免小写日单位警告。
- pandas 3 兼容修复包括 `fillna(method=...)`、`Series.iteritems()`、`convert_objects()`、字符串/类别颜色映射、日期转换与 ISO 周、聚合默认 `observed` 变化，以及 Matplotlib 3.11 colormap API。
- 全量测试首轮发现通用绘图器将 80 DPI 写进进程级 `savefig.dpi`，使后续质量/回归/时间序列独立图按 80 DPI 导出。移除全局赋值；绘图器保存仍显式传所设 DPI。新增 `test_plot_options_do_not_change_process_save_dpi`。
- 更正 `docs/release/v0.1.0-beta.3-baseline.md` 中源码提交后的旧“未提交”状态文字。
